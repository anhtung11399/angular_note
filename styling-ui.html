Style, thư viện UI và accessibility

View encapsulation, :host, biến CSS, Tailwind, Angular Material và CDK, animation, accessibility. So với scoped style của Vue.

Học xong bài này bạn sẽ:
  • Viết style component không rò rỉ
  • Dùng Angular Material / CDK
  • Làm giao diện truy cập được bằng bàn phím và trình đọc màn hình

#View encapsulation: style tự scoped

Style viết trong styles / styleUrl của component chỉ áp cho template của component đó, giống <style scoped> của Vue. Angular làm bằng cách gắn thuộc tính riêng vào phần tử và selector:

DOM thật
<app-class-card _nghost-ng-c123>
  <h3 _ngcontent-ng-c123>Lớp 5A</h3>
</app-class-card>
<style>h3[_ngcontent-ng-c123] { color: #dd0031; }</style>
Chế độÝ nghĩa
ViewEncapsulation.Emulated (mặc định)giả lập scoped bằng thuộc tính như trên
ViewEncapsulation.Nonestyle thành toàn cục (giống <style> không scoped)
ViewEncapsulation.ShadowDomdùng Shadow DOM thật của trình duyệt

#Các selector đặc biệt

class-card.css
:host {                         /* chính thẻ <app-class-card> */
  display: block;
  border: 1px solid var(--line);
  border-radius: 12px;
}
:host(.selected) { border-color: #dd0031; }        /* host có class selected */
:host-context(.dark) h3 { color: #fff; }           /* khi một tổ tiên có class dark */

/* Chọc vào component con / nội dung chiếu vào — hạn chế dùng */
:host ::ng-deep .mat-mdc-card-title { font-size: 18px; }
VueAngular
phần tử gốc của template:host (vì Angular có thẻ host bao ngoài)
:deep(.x)::ng-deep .x (đã đánh dấu sắp bỏ nhưng vẫn chạy, nên kèm :host phía trước)
:slotted(p)style nội dung chiếu vào: dùng ::ng-deep hoặc style toàn cục
v-bind() trong CSSbiến CSS gán qua host: host: { '[style.--accent]': 'color()' }

Muốn cho bên ngoài tuỳ biến component mà không cần ::ng-deep: dùng biến CSS. Component đọc var(--card-radius, 12px), nơi dùng đặt app-class-card { --card-radius: 4px; }. Biến CSS xuyên qua mọi ranh giới encapsulation.

#Animation

Từ Angular 20.2, hướng khuyên dùng là animation bằng CSS kèm animate.enter / animate.leave thay cho gói @angular/animations cũ:

Template
@if (open()) {
  <div class="toast" animate.enter="slide-in" animate.leave="fade-out">Đã lưu</div>
}
SCSS
.slide-in { animation: slide-in .2s ease-out; }
.fade-out { animation: fade-out .15s ease-in forwards; }
@keyframes slide-in { from { transform: translateY(12px); opacity: 0; } }
@keyframes fade-out { to { opacity: 0; } }

Tương đương <Transition name="slide"> của Vue: Angular gắn class khi phần tử vào và chờ animation leave chạy xong mới gỡ phần tử. Code cũ dùng trigger(), state(), transition() của @angular/animations, vẫn đọc được khi gặp.

#Accessibility

  • Dùng phần tử đúng nghĩa: <button> cho hành động, <a routerLink> cho điều hướng. Không gắn (click) lên div.
  • Nhãn cho ô nhập: <label for> hoặc aria-label.
  • Focus: hộp thoại phải giữ focus bên trong và trả focus khi đóng (CDK cdkTrapFocus, Dialog làm sẵn). Đổi trang thì đưa focus về tiêu đề chính.
  • Thông báo động: LiveAnnouncer của CDK đọc thông báo cho trình đọc màn hình (announcer.announce('Đã lưu điểm')).
  • Kiểm tra: ESLint có bộ luật template accessibility (@angular-eslint/template/accessibility), Lighthouse, axe DevTools.
eslint.config.js (ý tưởng)
{
  "files": ["**/*.html"],
  "extends": ["plugin:@angular-eslint/template/recommended", "plugin:@angular-eslint/template/accessibility"]
}

#Bài tập

Thẻ lớp học có chủ đề màu và hai chế độ sáng tối

Viết component ClassTile có input accent (màu), hiển thị tên lớp, số học sinh, thanh tiến độ nộp bài. Màu nhấn đổi theo input qua biến CSS. Tự động đổi màu nền / chữ theo chế độ tối của hệ điều hành. Thẻ có thể chọn bằng bàn phím (Enter / Space) và có viền focus rõ.

Gợi ý từng bước

  1. host: { '[style.--accent]': 'accent()', role: 'button', tabindex: '0', '(keydown.enter)': ..., '(keydown.space)': ... }.
  2. Style dùng var(--accent) cho viền trái và thanh tiến độ.
  3. Chế độ tối: biến --tile-bg, --tile-fg đổi trong @media (prefers-color-scheme: dark) đặt trong :host.
  4. :host(:focus-visible) { outline: 3px solid var(--accent); }.
Xem lời giải
class-tile.ts
import { Component, computed, input, output } from '@angular/core';

@Component({
  selector: 'app-class-tile',
  host: {
    role: 'button',
    tabindex: '0',
    '[style.--accent]': 'accent()',
    '[attr.aria-label]': '"Mở " + name()',
    '(click)': 'opened.emit()',
    '(keydown.enter)': 'opened.emit()',
    '(keydown.space)': '$event.preventDefault(); opened.emit()',
  },
  template: `
    <h3>{{ name() }}</h3>
    <p>{{ students() }} học sinh · đã nộp {{ percent() }}%</p>
    <div class="bar"><i [style.width.%]="percent()"></i></div>
  `,
  styles: `
    :host {
      --tile-bg: #fff; --tile-fg: #0f172a; --tile-track: #e2e8f0;
      display: block; padding: 14px 16px; border-radius: 12px; cursor: pointer;
      background: var(--tile-bg); color: var(--tile-fg);
      border: 1px solid var(--tile-track); border-left: 6px solid var(--accent, #dd0031);
    }
    @media (prefers-color-scheme: dark) {
      :host { --tile-bg: #1e293b; --tile-fg: #e2e8f0; --tile-track: #334155; }
    }
    :host(:focus-visible) { outline: 3px solid var(--accent, #dd0031); outline-offset: 2px; }
    h3 { margin: 0 0 4px; } p { margin: 0 0 8px; opacity: .8; }
    .bar { height: 8px; border-radius: 99px; background: var(--tile-track); overflow: hidden; }
    .bar i { display: block; height: 100%; background: var(--accent, #dd0031); }
  `,
})
export class ClassTile {
  name = input.required<string>();
  students = input(0);
  submitted = input(0);
  accent = input('#dd0031');
  opened = output();
  protected percent = computed(() => (this.students() ? Math.round((100 * this.submitted()) / this.students()) : 0));
}

Giải thích: [style.--accent] đặt biến CSS ngay trên thẻ host, mọi style bên trong đọc lại bằng var(--accent). Chế độ tối chỉ đổi giá trị biến, không phải viết lại style. role="button" + tabindex="0" + Enter / Space khiến thẻ dùng được bằng bàn phím như một nút thật; thẻ thứ hai trong hình đang được focus bằng phím Tab nên có viền. Space gọi preventDefault để trang không bị cuộn.
