Biểu thức trong template Angular là một tập con của JavaScript: có ?., ??, toán tử ba ngôi, gọi hàm, template literal (từ v19.2: {{ `Lớp ${name()}` }}). Không có: gán (=), new, ++, toán tử bit, truy cập biến toàn cục như window hay Math (muốn dùng thì gán vào thuộc tính của class).

Giữ biểu thức trong template đơn giản và rẻ. Gọi một method tính toán nặng như {{ tinhXepHang() }} sẽ bị chạy lại mỗi lần Angular kiểm tra giao diện. Đặt nó vào computed(): chỉ tính lại khi phụ thuộc đổi (giống computed của Vue so với method).

    Bài tập

    Thẻ bài tập có trạng thái và nút hành động

    Viết component hiển thị một bài tập: tiêu đề, hạn nộp, nhãn trạng thái có màu (nháp xám, đã giao xanh, quá hạn đỏ), nút "Giao bài" chỉ bật khi đang là nháp, và ô ghi chú nhập trực tiếp (hiển thị số ký tự đã gõ / 200).

    Gợi ý từng bước

    1. State: status = signal<'draft' | 'published'>('draft'), due = signal('2026-11-10'), note = signal('').
    2. Quá hạn: late = computed(() => this.status() === 'published' && this.due() < hôm nay) (so sánh chuỗi YYYY-MM-DD được).
    3. Nhãn: [class]="{ tag: true, gray: ..., green: ..., red: late() }".
    4. Nút: [disabled]="status() !== 'draft'", (click)="status.set('published')".
    5. Ghi chú: [value]="note()" và (input) cập nhật signal, maxlength="200".
    Xem lời giải 
    import { Component, computed, signal } from '@angular/core';

const today = () => new Date().toISOString().slice(0, 10);

@Component({
  selector: 'app-assignment-card',
  template: `
    
    Bài 3: Phân số
    
    
    Hạn nộp: {{ due() }}
    
    
      {{ late() ? 'Quá hạn' : status() === 'draft' ? 'Nháp' : 'Đã giao' }}
    
    

    
    
    {{ note().length }}/200
  `,
  styles: `
    :host { display: block; border: 1px solid #e2e8f0; border-radius: 12px; padding: 14px; }
    .tag { padding: 2px 10px; border-radius: 99px; font-size: 13px; margin-right: 8px; }
    .gray { background: #f1f5f9; } .green { background: #dcfce7; color: #166534; } .red { background: #fee2e2; color: #b91c1c; }
    textarea { display: block; width: 100%; margin-top: 6px; }
  `,
})
export class AssignmentCard {
  protected status = signal<'draft' | 'published'>('draft');
  protected due = signal('2026-11-10');
  protected note = signal('');
  protected late = computed(() => this.status() === 'published' && this.due() < today());

  protected onNote(e: Event) {
    this.note.set((e.target as HTMLTextAreaElement).value);
  }
}
