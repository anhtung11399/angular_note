Hydration yêu cầu DOM do server tạo và DOM trình duyệt định tạo phải khớp nhau. Nếu lệch (ví dụ hiển thị new Date() theo giờ server khác giờ máy người dùng, hay thao tác DOM trực tiếp), Angular báo lỗi NG0500 trong console và render lại phần đó.

@Injectable({ providedIn: 'root' })
export class Storage {
  private browser = isPlatformBrowser(inject(PLATFORM_ID));

  get(key: string): string | null {
    if (!this.browser) return null;
    try { return localStorage.getItem(key); } catch { return null; }
  }
  set(key: string, value: string) {
    if (!this.browser) return;
    try { localStorage.setItem(key, value); } catch { /* bị chặn */ }
  }
}

Không gọi API hai lần: HTTP transfer cache

Server gọi API để render, rồi trình duyệt hydrate và... gọi lại API đó lần nữa? Không: provideClientHydration bật sẵn transfer cache: response của các GET trong lúc SSR được nhúng vào HTML, phía trình duyệt dùng lại thay vì gọi lại.

provideClientHydration(withHttpTransferCacheOptions({ includePostRequests: false, filter: (req) => !req.url.includes('/me') }))

Request trên server cần URL tuyệt đối (server không biết "/api" là của ai) và cần chuyển tiếp cookie nếu API cần đăng nhập. Đừng để server render dữ liệu riêng của người dùng vào trang được cache chung (CDN).

SEO: tiêu đề, meta

export class InvitePage {
  code = input.required();
  private title = inject(Title);
  private meta = inject(Meta);
  invite = httpResource(() => `/api/invites/${this.code()}`);

  constructor() {
    effect(() => {
      const i = this.invite.value();
      if (!i) return;
      this.title.setTitle(`Tham gia ${i.className} trên Sổ bài tập`);
      this.meta.updateTag({ property: 'og:title', content: `Tham gia ${i.className}` });
      this.meta.updateTag({ property: 'og:image', content: i.coverUrl });
    });
  }
}

Deploy SSR

  • Node: chạy server.mjs (Express) trên VPS, Cloud Run, Render.
  • Edge / serverless: @angular/ssr có AngularAppEngine dùng Request / Response chuẩn web, chạy được trên Cloudflare Workers, Netlify, Vercel (với adapter phù hợp).
  • Chỉ prerender: nếu mọi route là Prerender hoặc Client, kết quả build là file tĩnh, deploy như CSR lên bất kỳ static hosting nào.

Bài tập

Trang link mời có ảnh xem trước khi chia sẻ

Bật SSR cho dự án. Trang /j/:code render phía server, hiển thị tên lớp và tên giáo viên lấy từ API, đặt og:title, og:description. Nút "Tham gia" dùng localStorage để nhớ mã lớp vừa mở. Không được lỗi khi render trên server.

Gợi ý từng bước

  1. ng add @angular/ssr, thêm { path: 'j/:code', renderMode: RenderMode.Server }.
  2. Dữ liệu: httpResource theo input code. Dùng URL tuyệt đối từ APP_CONFIG.
  3. Meta: effect khi có dữ liệu.
  4. localStorage: qua service Storage ở trên, ghi khi bấm nút (sự kiện chỉ có trên trình duyệt).
  5. Kiểm tra: curl http://localhost:4000/j/DEMO5A phải thấy tên lớp và thẻ meta trong HTML.

    } @else if (invite.error()) {
      
Link mời không tồn tại hoặc đã hết hạn.

    } @else {
      
Đang tải…

    }
  `,

export class InvitePage {
  code = input.required();
  private cfg = inject(APP_CONFIG);
  private storage = inject(Storage);
  private router = inject(Router);
  private title = inject(Title);
  private meta = inject(Meta);

  protected invite = httpResource<{ className: string; teacherName: string }>(
    () => `${this.cfg.apiUrl}/invites/${encodeURIComponent(this.code())}`,
  );

  constructor() {
    effect(() => {
      const i = this.invite.value();
      if (!i) return;
      const t = `Tham gia ${i.className} trên Sổ bài tập`;
      this.title.setTitle(t);
      this.meta.updateTag({ property: 'og:title', content: t });
      this.meta.updateTag({ property: 'og:description', content: `Giáo viên ${i.teacherName} mời bạn vào lớp.` });
    });
  }

  protected join() {
    this.storage.set('last-invite', this.code());
    this.router.navigate(['/dang-nhap'], { queryParams: { ma: this.code() } });
  }
}
