Nhận tham số route bằng input

Với withComponentInputBinding(), tham số đường dẫn, query param và data của route được gán thẳng vào input cùng tên:

export class GradingPage {
  classId = input.required();          // từ :classId của route cha (cần paramsInheritanceStrategy: 'always')
  mon = input();                        // từ ?mon=toan
  em = input();                         // từ ?em=7

  subject = computed(() => this.mon() ?? 'toan');
}

Tham số luôn là chuỗi. Dùng transform: numberAttribute nếu cần số: classId = input.required({ transform: numberAttribute }). Vì input là signal, khi URL đổi từ /lop/1 sang /lop/2, mọi computed và httpResource dựa trên nó tự chạy lại.

Guard dạng hàm

import { CanActivateFn, Router } from '@angular/router';

export const authGuard: CanActivateFn = (route, state) => {
  const auth = inject(Auth);
  if (auth.isLoggedIn()) return true;
  // trả về UrlTree = chuyển hướng (không gọi navigate trong guard)
  return inject(Router).createUrlTree(['/dang-nhap'], { queryParams: { next: state.url } });
};

export const teacherOnly: CanMatchFn = () => inject(Auth).isTeacher();

Bài tập

Khu vực lớp học có menu con, guard và trang 404

Dựng router cho: / trang chủ, /lop danh sách lớp (cần đăng nhập), /lop/:classId/bai-tap và /lop/:classId/hoc-sinh dùng chung layout có menu hai mục và tiêu đề "Lớp {{ classId }}", mọi URL khác vào trang 404. Đăng nhập giả bằng một signal trong service Auth.

Gợi ý từng bước

  1. provideRouter(routes, withComponentInputBinding()) và trong provideRouter thêm withRouterConfig({ paramsInheritanceStrategy: 'always' }) để route con nhận classId của cha.
  2. Route lop/:classId có component: ClassLayout và children.
  3. ClassLayout: input classId, template có hai routerLink tương đối và <router-outlet />.
  4. Guard: inject(Auth).loggedIn() || inject(Router).createUrlTree(['/']).
