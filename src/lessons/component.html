Selector và thẻ host

Khi Angular render <app-class-card>, thẻ đó thật sự xuất hiện trong DOM, bao quanh nội dung template. Vue thì không: component Vue thay thế bằng phần tử gốc của template.

Thẻ host mặc định là display: inline (vì trình duyệt coi thẻ lạ là inline). Khi đặt component vào flex / grid hoặc cho nó width, nhớ thêm vào style của component: :host { display: block; }. Đây là lỗi bố cục số một của người mới.

Quy ước selector:

  • Có tiền tố của dự án (mặc định app-, có thể đổi trong angular.json) để không trùng thẻ HTML hay thư viện khác.
  • Viết kebab-case: app-class-card.
  • Selector còn có thể là thuộc tính [appTooltip] hay class, nhưng đó là cho directive (bài {{n:directive-pipe}}).

imports: component phải tự khai báo những gì nó dùng

Đây là điểm khác lớn nhất với Vue <script setup>. Template Angular chỉ hiểu những component, directive, pipe có trong imports của chính component đó.

Cơ chế này giống đăng ký component cục bộ của Vue Options API (components: { Badge }), không phải đăng ký toàn cục app.component(). Angular không có đăng ký toàn cục: mọi phụ thuộc phải ghi rõ, nhờ vậy builder biết chính xác component nào cần đóng gói, và lazy loading tách bundle rất chuẩn.

  • Component "thông minh" (container, smart): biết lấy dữ liệu ở đâu (inject service), xử lý sự kiện, điều hướng. Thường là component của một trang.
  • Component "trình bày" (presentational, dumb): chỉ nhận input, phát output, không inject service dữ liệu. Dễ dùng lại và dễ test.

Đây đúng là cách bạn tổ chức Vue tốt: trang gọi composable / store, component con chỉ nhận props và emit. Angular không bắt buộc, nhưng hầu hết dự án lớn theo cách này.

Component cũ với NgModule

Trong dự án viết trước Angular 15, component được khai báo trong NgModule thay vì tự imports:

@NgModule({
  declarations: [ClassListComponent, ClassCardComponent], // component "thuộc" module này
  imports: [CommonModule, SharedModule, ClassesRoutingModule],
  exports: [ClassCardComponent],
})
export class ClassesModule {}

@Component({
  selector: 'app-class-card',
  templateUrl: './class-card.component.html',
  standalone: false,            // từ v19 standalone là mặc định, component cũ phải ghi rõ false
})
export class ClassCardComponent {}

Component standalone và component trong NgModule dùng chung được: module import component standalone, component standalone import module. Lệnh ng g @angular/core:standalone giúp chuyển dần dự án cũ sang standalone.

Bài tập

Component StudentRow và danh sách

Viết component StudentRow hiển thị tên học sinh, số bài đã nộp trên tổng số bài, và tô đỏ nếu nộp dưới một nửa. Viết StudentList dùng StudentRow cho 3 học sinh cố định.

Gợi ý từng bước

  1. StudentRow: 3 input bắt buộc name, done, total.
  2. Dùng computed để tính low = done / total < 0.5.
  3. Tô đỏ bằng host binding: host: { '[class.low]': 'low()' } và style :host(.low) { color: #dc2626; }.
  4. StudentList import StudentRow, dùng @for qua một mảng (bài {{n:control-flow}} sẽ nói kỹ, ở đây chỉ cần @for (s of students; track s.id) { ... }).
Xem lời giải 
import { Component, computed, input } from '@angular/core';

@Component({
  selector: 'app-student-row',
  template: `
    {{ name() }}
    {{ done() }} / {{ total() }} bài
  `,
  styles: `
    :host { display: flex; justify-content: space-between; padding: 8px 12px; border-bottom: 1px solid #e2e8f0; }
    :host(.low) { color: #dc2626; font-weight: 600; }
  `,
  host: { '[class.low]': 'low()' },
})
export class StudentRow {
  name = input.required();
  done = input.required();
  total = input.required();
  protected low = computed(() => this.total() > 0 && this.done() / this.total() < 0.5);
}

import { Component } from '@angular/core';
import { StudentRow } from './student-row';

@Component({
  selector: 'app-student-list',
  imports: [StudentRow],
  template: `
    @for (s of students; track s.id) {
      
    }
  `,
})
export class StudentList {

}
