Bật HttpClient

HttpClient thay cho Axios / fetch trong dự án Vue. Có sẵn: JSON tự động, kiểu dữ liệu, interceptor (giống interceptor của Axios), tiến trình upload, huỷ request, và công cụ giả lập khi test. Điểm khác: nó trả Observable, không phải Promise.

Gọi API cơ bản

@Injectable({ providedIn: 'root' })
export class AssignmentApi {
  private http = inject(HttpClient);
  private base = '/api/assignments';

  list(classId: number, page = 1) {
    const params = new HttpParams().set('classId', classId).set('page', page);
    return this.http.get>(this.base, { params });
  }

  get(id: number) {
    return this.http.get(`${this.base}/${id}`);
  }

  create(data: NewAssignment) {
    return this.http.post(this.base, data);
  }

  update(id: number, patch: AssignmentPatch) {
    return this.http.patch(`${this.base}/${id}`, patch);
  }

  remove(id: number) {
    return this.http.delete(`${this.base}/${id}`);
  }
}

Observable từ HttpClient là lạnh (cold): gọi api.create(data) mà không subscribe thì không có request nào được gửi. Đây là bẫy số một của người từ Promise sang. Ngược lại, subscribe hai lần là gửi hai request.

// Ba cách "chạy" một Observable từ HttpClient
this.api.create(data).subscribe({ next: (a) => ..., error: (e) => ... });  // 1. subscribe
const a = await firstValueFrom(this.api.create(data));                     // 2. đổi sang Promise, dùng async/await
assignments = toSignal(this.api.list(5), { initialValue: emptyPage });      // 3. đổi sang signal (đọc dữ liệu)

Với hành động (lưu, xoá, đăng nhập), firstValueFrom + async / await là cách gần với thói quen Vue nhất và hoàn toàn hợp lệ.

Interceptor dạng hàm

Interceptor chen vào mọi request và response: gắn token, thêm header, bắt lỗi chung, đo thời gian, hiện thanh loading.

import { HttpInterceptorFn } from '@angular/common/http';

export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const token = inject(Auth).token();
  if (!token || !req.url.startsWith('/api')) return next(req);   // chỉ gắn cho API của mình
  return next(req.clone({ setHeaders: { Authorization: `Bearer ${token}` } }));
};

export const errorInterceptor: HttpInterceptorFn = (req, next) => {
  const router = inject(Router);
  const toast = inject(Toast);
  return next(req).pipe(
    catchError((err: HttpErrorResponse) => {
      if (err.status === 401) {
        router.navigate(['/dang-nhap'], { queryParams: { next: router.url } });
      } else if (err.status === 0) {
        toast.error('Mất kết nối mạng');
      } else if (err.status >= 500) {
        toast.error('Máy chủ đang bận, thử lại sau');
      }
      return throwError(() => err);   // vẫn ném lỗi tiếp cho nơi gọi xử lý riêng
    }),
  );
};

HttpRequest là bất biến: req.headers.set(...) trả object mới và không có tác dụng nếu bạn không dùng nó. Luôn dùng req.clone({...}).

Xử lý lỗi theo từng chỗ

async save() {
  this.saving.set(true);
  try {
    const a = await firstValueFrom(this.api.create(this.form.getRawValue()));
    this.toast.success('Đã giao bài');
    this.router.navigate(['/lop', a.classId, 'bai-tap']);
  } catch (e) {
    const err = e as HttpErrorResponse;
    if (err.status === 422) {
      // lỗi validate từ server: gắn vào ô tương ứng
      const fields = err.error?.error?.fields ?? {};
      for (const [k, msg] of Object.entries(fields)) this.form.get(k)?.setErrors({ server: msg });
    } else if (err.status === 402) {
      this.toast.error(err.error?.error?.message ?? 'Lớp đã bị khoá');
    }
  } finally {
    this.saving.set(false);
  }
}

HttpErrorResponse.error là body JSON server trả về, status là mã HTTP (0 khi mất mạng hoặc bị CORS chặn).

Upload file có tiến trình

upload(file: File) {
  const body = new FormData();
  body.append('file', file);
  return this.http.post<{ key: string }>('/api/uploads', body, { reportProgress: true, observe: 'events' }).pipe(
    map((ev) => {
      if (ev.type === HttpEventType.UploadProgress) return { progress: Math.round((100 * ev.loaded) / (ev.total ?? 1)) };
      if (ev.type === HttpEventType.Response) return { done: ev.body!.key };
      return null;
    }),
    filter((x) => x !== null),
  );
}

Không đặt header Content-Type khi gửi FormData: trình duyệt tự đặt kèm boundary.

Bài tập

Danh sách học sinh có tìm kiếm, phân trang và xoá

Dùng API giả https://jsonplaceholder.typicode.com/users (hoặc API của bạn). Viết trang hiển thị danh sách, có ô tìm (lọc phía server bằng query ?q= nếu API hỗ trợ, ở đây lọc phía client), trạng thái đang tải và lỗi có nút thử lại, nút xoá từng dòng (gọi DELETE, xoá khỏi danh sách ngay khi thành công). Thêm interceptor in ra console thời gian mỗi request.

Gợi ý từng bước

  1. users = httpResource<User[]>(() => 'https://jsonplaceholder.typicode.com/users').
  2. shown = computed(() => (this.users.value() ?? []).filter(...)) theo query().
  3. Xoá: await firstValueFrom(http.delete(url)) rồi this.users.update(list => list?.filter(u => u.id !== id)): sửa giá trị cục bộ, không tải lại.
  4. Interceptor: ghi performance.now() trước, dùng finalize(() => console.log(...)) sau.
Xem lời giải 
import { HttpInterceptorFn } from '@angular/common/http';
import { finalize } from 'rxjs';

export const timingInterceptor: HttpInterceptorFn = (req, next) => {
  const t0 = performance.now();
  return next(req).pipe(finalize(() => console.log(`${req.method} ${req.urlWithParams} ${Math.round(performance.now() - t0)}ms`)));
};

import { Component, computed, inject, signal } from '@angular/core';
import { HttpClient, httpResource } from '@angular/common/http';
import { firstValueFrom } from 'rxjs';

interface User { id: number; name: string; email: string }
const URL = 'https://jsonplaceholder.typicode.com/users';

@Component({
  selector: 'app-users-page',
  template: `
    
    @if (users.isLoading()) {
      
Đang tải…

    } @else if (users.error()) {
      
Không tải được. 

    } @else {
      
    
        @for (u of shown(); track u.id) {
          
  • {{ u.name }} {{ u.email }}
            
          
    • 
        } @empty { 
  • Không có ai khớp "{{ query() }}"
    •  }
      

    }
  `,
})
export class UsersPage {
  private http = inject(HttpClient);
  protected query = signal('');
  protected removing = signal(null);
  protected users = httpResource(() => URL);
  protected shown = computed(() => {
    const q = this.query().toLowerCase();
    return (this.users.value() ?? []).filter((u) => u.name.toLowerCase().includes(q));
  });

  protected async remove(id: number) {
    this.removing.set(id);
    try {
      await firstValueFrom(this.http.delete(`${URL}/${id}`));
      this.users.update((list) => list?.filter((u) => u.id !== id));
    } finally {
      this.removing.set(null);
    }
  }
}

Giải thích: sau khi xoá, users.update(...) sửa dữ liệu cục bộ của resource (trạng thái chuyển thành 'local') nên danh sách cập nhật ngay mà không gọi lại API. jsonplaceholder không xoá thật trên server, nhưng trả 200 nên luồng giống API thật. removing tắt nút của dòng đang xoá để người dùng không bấm hai lần.
