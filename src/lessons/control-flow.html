track là bắt buộc

Khác Vue (nơi :key chỉ là khuyến nghị và có cảnh báo), track trong Angular bắt buộc, thiếu là lỗi biên dịch. Nó cho Angular biết phần tử nào là phần tử nào khi danh sách đổi, để giữ DOM cũ thay vì xoá đi tạo lại.

@defer: tải lười một phần giao diện

@defer tách nội dung (và mọi component, directive, pipe bên trong) thành một chunk JavaScript riêng, chỉ tải khi điều kiện xảy ra. Đây là thứ Vue làm bằng defineAsyncComponent + <Suspense>, nhưng Angular làm bằng cú pháp template, không cần sửa code TypeScript.

    Bài tập

    Bảng điểm có lọc, trạng thái rỗng và phần thống kê tải lười

    Viết component hiển thị danh sách bài nộp: mỗi dòng có số thứ tự, tên học sinh, trạng thái (dùng @switch), dòng chẵn tô nền nhạt. Có nút lọc "Chỉ chưa nộp". Khi danh sách lọc rỗng hiện "Tất cả đã nộp". Phần thống kê (component Stats) chỉ tải khi người dùng bấm vào khung "Xem thống kê".

    Gợi ý từng bước

    1. Dữ liệu: signal chứa mảng 5 bài nộp, onlyMissing = signal(false), shown = computed(...) lọc theo cờ.
    2. @for (s of shown(); track s.id; let i = $index, even = $even), gắn [class.even]="even".
    3. @empty cho trường hợp rỗng.
    4. @defer (on interaction) { <app-stats [subs]="subs()" /> } @placeholder { <button>Xem thống kê</button> }.

export class SubmissionTable {
  protected subs = signal([
    { id: 1, name: 'An', status: 'graded', score: 9 },
    { id: 2, name: 'Bình', status: 'missing' },

}

    import { Component, computed, input } from '@angular/core';

@Component({
  selector: 'app-stats',
  template: `
    Đã nộp {{ done() }}/{{ subs().length }} · điểm trung bình {{ avg() }}
    `,
})
export class Stats {
  subs = input.required<{ status: string; score?: number }[]>();
  protected done = computed(() => this.subs().filter((s) => s.status !== 'missing').length);
  protected avg = computed(() => {
    const g = this.subs().filter((s) => s.score != null);
    return g.length ? (g.reduce((t, s) => t + s.score!, 0) / g.length).toFixed(1) : '—';
  });
}
