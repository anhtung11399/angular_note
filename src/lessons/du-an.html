Backend giả để làm ngay

Chưa có backend? Viết một interceptor trả dữ liệu giả, sau này thay bằng API thật mà không sửa component nào (nhờ DI và interceptor). Chỉ bật khi phát triển.

import { HttpInterceptorFn, HttpResponse } from '@angular/common/http';
import { delay, of, throwError } from 'rxjs';

const db = {
  users: [
    { id: 1, email: 'gv@demo.vn', name: 'Cô Hoa', role: 'teacher' as const },
    { id: 2, email: 'ph@demo.vn', name: 'Anh Nam', role: 'parent' as const, childId: 7 },
  ],
  classes: [{ id: 1, name: 'Lớp 5A', capacity: 30, teacherId: 1 }],
  assignments: [
    { id: 6, classId: 1, subject: 'toan', title: 'Bài 6: Phân số', dueDate: '2026-11-08', exerciseCount: 4 },
    { id: 7, classId: 1, subject: 'toan', title: 'Bài 7: Đo thời gian', dueDate: '2026-11-05', exerciseCount: 3 },
  ],
  submissions: [] as { id: number; assignmentId: number; studentId: number; score: number | null; comment: string; images: string[] }[],
};
let session: (typeof db.users)[number] | null = null;

const ok = (body: T) => of(new HttpResponse({ status: 200, body })).pipe(delay(250));
const fail = (status: number, message: string) =>
  throwError(() => ({ status, error: { error: { code: String(status), message } } })).pipe(delay(250));

export const fakeBackend: HttpInterceptorFn = (req, next) => {
  if (!req.url.startsWith('/api/')) return next(req);
  const path = req.url.replace('/api', '');

  if (path === '/login' && req.method === 'POST') {
    const u = db.users.find((x) => x.email === (req.body as { email: string }).email);
    return u ? ((session = u), ok(u)) : fail(401, 'Email chưa đăng ký');
  }
  if (!session) return fail(401, 'Bạn cần đăng nhập');
  if (path === '/me') return ok(session);
  if (path === '/classes') return ok(db.classes.filter((c) => c.teacherId === session!.id));

  const m = path.match(/^\/classes\/(\d+)\/assignments$/);
  if (m && req.method === 'GET') {
    const subject = req.params.get('subject') ?? 'toan';
    return ok(db.assignments.filter((a) => a.classId === +m[1] && a.subject === subject));
  }
  if (m && req.method === 'POST') {
    const a = { ...(req.body as object), id: Date.now(), classId: +m[1] } as (typeof db.assignments)[number];
    db.assignments.unshift(a);
    return ok(a);
  }
  return fail(404, 'Không tìm thấy');
};

providers: [
  provideHttpClient(withFetch(), withInterceptors([
    ...(isDevMode() ? [fakeBackend] : []),
    authInterceptor,
    errorInterceptor,
  ])),
]

Thứ tự bài tập: sắp đến hạn lên đầu

// Bài còn ≤ 1 ngày đến hạn mà chưa nộp lên đầu, rồi bài giao gần nhất
export function sortAssignments(list: readonly T[], today: string): T[] {
  const tomorrow = addDays(today, 1);
  const soon = (a: T) => !a.submitted && a.dueDate >= today && a.dueDate <= tomorrow;
  return [...list].sort((a, b) => Number(soon(b)) - Number(soon(a)) || b.id - a.id);
}

function addDays(d: string, n: number) {
  const t = new Date(d + 'T00:00:00Z');
  t.setUTCDate(t.getUTCDate() + n);
  return t.toISOString().slice(0, 10);
}

Tiêu chí hoàn thành

  • Chức năng: đủ các luồng ở bảng đề bài cho cả hai vai trò.
  • Code: standalone, signals cho mọi state hiển thị, không subscribe nào thiếu huỷ, không any trừ chỗ thật cần, OnPush cho mọi component.
  • Trải nghiệm: mọi danh sách có trạng thái đang tải, lỗi (có thử lại), rỗng; sau mỗi thao tác giao diện cập nhật ngay; dùng tốt ở màn hình 390px (không cuộn ngang).
  • Hiệu năng: mọi route lazy, bundle ban đầu dưới 300 KB, thư viện nặng tải lười.
  • Chất lượng: test pass, lint sạch, CI chạy mỗi lần push.
  • Bảo mật: không bypass sanitizer, không bí mật trong bundle, next chỉ nhận đường dẫn nội bộ.
  • Deploy: có link chạy thật, tải lại ở trang con không bị 404.

Mở rộng khi đã xong

  • Bật SSR, prerender trang giới thiệu, render server cho link mời /j/:code có ảnh xem trước (bài {{n:ssr}}).
  • Thông báo đẩy khi có bài mới bằng service worker (bài {{n:i18n-pwa}}).
  • Chuyển store chấm bài sang NgRx SignalStore để so sánh (bài {{n:state}}).
  • Viết lại một màn hình bằng signal forms để cảm nhận hướng đi mới của Angular (bài {{n:forms}}).
  • Thêm sơ đồ chỗ ngồi kéo thả bằng CDK Drag and Drop.
Mốc 2 làm mẫu: đăng nhập có chuyển hướng theo vai trò

Để bạn có điểm bắt đầu, đây là lời giải đầy đủ cho mốc khó nhất ở phần đầu.

Gợi ý từng bước

  1. Auth giữ user signal, có login(), restore() (gọi /api/me khi tải trang), logout().
  2. Khôi phục phiên trước khi router chạy guard: provideAppInitializer(() => inject(Auth).restore()).
  3. Guard trả UrlTree tới /dang-nhap?next=....
  4. Trang login: reactive form, lỗi từ server hiển thị dưới form, đăng nhập xong navigateByUrl(safeNext(next)).
Xem lời giải 
@Injectable({ providedIn: 'root' })
export class Auth {
  private http = inject(HttpClient);
  private readonly _user = signal(null);
  readonly user = this._user.asReadonly();
  readonly isLoggedIn = computed(() => !!this._user());
  readonly isTeacher = computed(() => this._user()?.role === 'teacher');

  async restore() {
    try {
      this._user.set(await firstValueFrom(this.http.get('/api/me')));
    } catch {
      this._user.set(null); // chưa đăng nhập: bình thường
    }
  }

  async login(email: string) {
    this._user.set(await firstValueFrom(this.http.post('/api/login', { email })));
  }

  logout() {
    this._user.set(null);
  }
}

export const authGuard: CanActivateFn = (_r, state) =>
  inject(Auth).isLoggedIn() || inject(Router).createUrlTree(['/dang-nhap'], { queryParams: { next: state.url } });

export const roleGuard = (role: User['role']): CanMatchFn => () => inject(Auth).user()?.role === role;

export class LoginPage {
  next = input();                                // ?next=
  private auth = inject(Auth);
  private router = inject(Router);
  protected busy = signal(false);
  protected error = signal('');
  protected form = inject(FormBuilder).nonNullable.group({ email: ['', [Validators.required, Validators.email]] });

  async submit() {
    if (this.form.invalid) return this.form.markAllAsTouched();
    this.busy.set(true);
    this.error.set('');
    try {
      await this.auth.login(this.form.getRawValue().email);
      this.router.navigateByUrl(safeNext(this.next()));
    } catch (e) {
      this.error.set((e as HttpErrorResponse).error?.error?.message ?? 'Không đăng nhập được');
    } finally {
      this.busy.set(false);
    }
  }
}
