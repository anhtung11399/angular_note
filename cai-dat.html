Cài Angular CLI và dự án đầu tiên

ng new, cấu trúc thư mục, angular.json, ng serve / build / generate, bootstrap ứng dụng, so với Vite + Vue.

Học xong bài này bạn sẽ:
  • Tạo và chạy được một dự án Angular
  • Hiểu từng file trong dự án mới tạo
  • Dùng thành thạo các lệnh ng hay dùng

#Cài Angular CLI

Ở Vue bạn tạo dự án bằng npm create vue@latest (create-vue, dùng Vite). Angular có Angular CLI: không chỉ tạo dự án mà còn sinh code, chạy dev server, build, test, và nâng cấp phiên bản.

Terminal
node -v                       # cần Node LTS đang được hỗ trợ (xem angular.dev/reference/versions)
npm install -g @angular/cli   # cài lệnh ng toàn cục
ng version
Terminal — kết quả minh hoạMô phỏng
$ ng version
Angular CLI       : 20.3.x
Node              : 22.x
Package Manager   : npm 10.x
OS                : darwin arm64

Phiên bản cụ thể trên máy bạn có thể khác (Angular ra bản lớn mỗi 6 tháng). Mọi thứ trong lộ trình chạy với Angular 20 trở lên.

Không muốn cài toàn cục? Dùng npx @angular/cli new ten-du-an. Trong dự án đã có, các lệnh ng chạy được qua npx ng ... hoặc script trong package.json.

#Từng file trong dự án mới

cấu trúc thư mục
so-bai-tap/
├── angular.json            cấu hình build / serve / test (giống vite.config.ts)
├── package.json
├── tsconfig.json           TypeScript strict + angularCompilerOptions
├── tsconfig.app.json
├── public/                 file tĩnh copy nguyên (favicon, ảnh) — giống public/ của Vite
└── src/
    ├── index.html          trang HTML gốc, có thẻ <app-root>
    ├── main.ts             điểm khởi động: bootstrapApplication(App, appConfig)
    ├── styles.css          CSS toàn cục
    └── app/
        ├── app.ts          component gốc (giống App.vue)
        ├── app.html        template của component gốc
        ├── app.css
        ├── app.config.ts   cấu hình ứng dụng: router, http, ... (giống app.use(...) trong main.ts của Vue)
        └── app.routes.ts   danh sách route
src/main.ts
import { bootstrapApplication } from '@angular/platform-browser';
import { appConfig } from './app/app.config';
import { App } from './app/app';

bootstrapApplication(App, appConfig)
  .catch((err) => console.error(err));
src/app/app.config.ts
import { ApplicationConfig, provideBrowserGlobalErrorListeners, provideZonelessChangeDetection } from '@angular/core';
import { provideRouter } from '@angular/router';
import { routes } from './app.routes';

export const appConfig: ApplicationConfig = {
  providers: [
    provideBrowserGlobalErrorListeners(),
    provideZonelessChangeDetection(), // ứng dụng không dùng zone.js (mặc định từ v21 thì không cần dòng này)
    provideRouter(routes),
  ],
};

Đối chiếu với Vue:

main.ts (Vue, để so sánh)
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import App from './App.vue'
import router from './router'

createApp(App).use(createPinia()).use(router).mount('#app')
VueAngular
createApp(App).mount('#app')bootstrapApplication(App, appConfig), gắn vào thẻ có selector của App (<app-root>)
app.use(router)provideRouter(routes) trong providers
app.use(pinia)không cần: service có providedIn: 'root' tự có sẵn
app.config.errorHandlerprovideBrowserGlobalErrorListeners() + ErrorHandler

Mọi "plugin" của Angular đều có dạng hàm provideXxx(): provideHttpClient(), provideAnimations(), provideServiceWorker()... Bạn sẽ thêm dần vào mảng providers.

#Component gốc

src/app/app.ts
import { Component, signal } from '@angular/core';
import { RouterOutlet } from '@angular/router';

@Component({
  selector: 'app-root',          // tên thẻ HTML
  imports: [RouterOutlet],       // component / directive dùng trong template
  templateUrl: './app.html',     // template ở file riêng
  styleUrl: './app.css',
})
export class App {
  protected readonly title = signal('so-bai-tap');
}
src/app/app.html (rút gọn)
<h1>Xin chào, {{ title() }}</h1>
<router-outlet />

<router-outlet /> giống <RouterView /> của vue-router: chỗ hiển thị component của route hiện tại.

Quy ước đặt tên từ Angular 20: file app.ts, class App (không còn hậu tố .component.ts và AppComponent). Dự án cũ thì là app.component.ts / AppComponent. Cả hai đều đúng, cứ theo quy ước của dự án.

Thêm --inline-template --inline-style (hay -t -s) nếu muốn template và style nằm luôn trong file .ts, giống SFC. --skip-tests để không sinh file test. --dry-run xem trước sẽ tạo gì.

Vue không có tương đương chính thức (bạn tự tạo file). Lúc đầu thấy thừa, nhưng ở dự án nhiều người, ng g giúp mọi file theo một khuôn: đúng tên, đúng chỗ, có sẵn file test.

#Biên dịch AOT: điều khác biệt quan trọng

Template Vue được biên dịch thành hàm render (lúc build với SFC). Angular cũng vậy nhưng chặt hơn: trình biên dịch Angular (AOT, Ahead-of-Time) kiểm tra kiểu cả template.

Terminal — kết quả minh hoạMô phỏng
$ ng build
✘ [ERROR] NG9: Property 'titel' does not exist on type 'App'. [plugin angular-compiler]

    src/app/app.html:1:17:
      1 │ <h1>Xin chào, {{ titel() }}</h1>
        ╵                  ~~~~~

Gõ sai titel thay vì title: build dừng, chỉ đúng dòng. Trong Vue, lỗi tương tự thường chỉ hiện cảnh báo lúc chạy (hoặc khi bạn bật vue-tsc).

#Công cụ nên cài

  • Angular Language Service (extension VS Code): gợi ý và báo lỗi trong template, nhảy tới định nghĩa. Giống Volar (Vue - Official) của Vue.
  • Angular DevTools (extension Chrome / Firefox): xem cây component, giá trị input, signal, đo hiệu năng. Giống Vue DevTools.
  • ESLint cho Angular: ng add @angular-eslint/schematics.
  • Prettier: dùng như bình thường. Prettier hiểu cú pháp control flow mới của Angular.

Câu hỏi nhanh. Ở Vue bạn thêm router bằng app.use(router). Ở Angular hiện đại, bạn thêm router ở đâu?

Ứng dụng standalone cấu hình mọi thứ qua các hàm provideXxx() trong app.config.ts. RouterModule.forRoot chỉ còn ở dự án dùng NgModule.

Câu hỏi nhanh. Lệnh nào nâng cấp Angular lên bản mới và tự sửa code theo các thay đổi phá vỡ?

ng update chạy các migration (schematic) do đội Angular viết, tự sửa code cũ sang cú pháp mới.

#Bài tập

Tạo dự án và trang chào đầu tiên

Tạo dự án so-bai-tap, xoá nội dung mẫu trong app.html, sinh component welcome hiển thị "Chào mừng giáo viên" kèm ngày hôm nay, và đặt nó vào component gốc.

Gợi ý từng bước

  1. ng new so-bai-tap --style=css --ssr=false --zoneless, rồi ng g c welcome -t -s --skip-tests.
  2. Trong welcome.ts: thêm thuộc tính today = new Date().
  3. Hiển thị ngày bằng pipe có sẵn: {{ today | date:'dd/MM/yyyy' }}. Pipe date cần import DatePipe vào imports của component.
  4. Trong app.ts: thêm Welcome vào imports, trong app.html đặt <app-welcome />.
Xem lời giải
src/app/welcome/welcome.ts
import { Component } from '@angular/core';
import { DatePipe } from '@angular/common';

@Component({
  selector: 'app-welcome',
  imports: [DatePipe],
  template: `
    <h1>Chào mừng giáo viên</h1>
    <p>Hôm nay: {{ today | date: 'dd/MM/yyyy' }}</p>
  `,
  styles: `h1 { color: #dd0031; }`,
})
export class Welcome {
  today = new Date();
}
src/app/app.ts
import { Component } from '@angular/core';
import { RouterOutlet } from '@angular/router';
import { Welcome } from './welcome/welcome';

@Component({
  selector: 'app-root',
  imports: [RouterOutlet, Welcome],
  templateUrl: './app.html',
})
export class App {}
src/app/app.html
<app-welcome />
<router-outlet />
localhost:4200Minh hoạ

Hôm nay: 04/11/2026

Giải thích: quên thêm Welcome vào imports của App thì build báo NG8001: 'app-welcome' is not a known element. Đây là lỗi hay gặp nhất của người mới: mỗi component phải tự khai báo những component con nó dùng. Ở Vue với <script setup>, chỉ cần import là xong. Ở Angular, cần cả import TypeScript lẫn imports: [...] của decorator.
