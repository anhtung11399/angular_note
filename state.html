Quản lý state

State trong service với signals (thay cho Pinia), NgRx SignalStore, NgRx Store cổ điển, khi nào cần thư viện. Cập nhật lạc quan và đồng bộ với server.

Học xong bài này bạn sẽ:
  • Viết store bằng service + signals
  • Đọc hiểu NgRx SignalStore và Store
  • Chọn mức quản lý state phù hợp dự án

#Ba mức quản lý state

Lời khuyên của chính đội Angular và cộng đồng: bắt đầu từ mức 1, lên mức 2 khi hai component không cha con cần cùng dữ liệu, và chỉ lên mức 3 khi có lý do rõ ràng.

#Store bằng service + signals

features/classes/class-store.ts
import { Injectable, computed, inject, signal } from '@angular/core';
import { firstValueFrom } from 'rxjs';

interface ClassState {
  items: readonly Classroom[];
  loading: boolean;
  error: string | null;
  selectedId: number | null;
}

@Injectable({ providedIn: 'root' })
export class ClassStore {
  private api = inject(ClassApi);
  private readonly state = signal<ClassState>({ items: [], loading: false, error: null, selectedId: null });

  // "getters" — chỉ đọc
  readonly items = computed(() => this.state().items);
  readonly loading = computed(() => this.state().loading);
  readonly error = computed(() => this.state().error);
  readonly selected = computed(() => this.state().items.find((c) => c.id === this.state().selectedId) ?? null);
  readonly totalStudents = computed(() => this.state().items.reduce((t, c) => t + c.students, 0));

  // "actions"
  async load() {
    this.patch({ loading: true, error: null });
    try {
      const items = await firstValueFrom(this.api.list());
      this.patch({ items, loading: false });
    } catch {
      this.patch({ loading: false, error: 'Không tải được danh sách lớp' });
    }
  }

  select(id: number | null) {
    this.patch({ selectedId: id });
  }

  async rename(id: number, name: string) {
    const before = this.state().items;
    this.patch({ items: before.map((c) => (c.id === id ? { ...c, name } : c)) }); // cập nhật lạc quan
    try {
      await firstValueFrom(this.api.update(id, { name }));
    } catch {
      this.patch({ items: before, error: 'Đổi tên không thành công' });         // hoàn tác
    }
  }

  private patch(p: Partial<ClassState>) {
    this.state.update((s) => ({ ...s, ...p }));
  }
}

#Cập nhật lạc quan và đồng bộ với server

Hai nguyên tắc cho trải nghiệm tốt:

  • Sau mỗi thao tác, cập nhật state tại chỗ, không gọi lại API chỉ để làm mới danh sách. Ví dụ chấm điểm xong: sửa đúng phần tử đó và giảm số "cần chấm" ở menu.
  • Cập nhật lạc quan cho thao tác gần như luôn thành công (đổi tên, đánh dấu): đổi giao diện ngay, gọi API, lỗi thì hoàn tác và báo.
TypeScript
async grade(subId: number, score: number) {
  const s = this.state();
  this.patch({
    subs: s.subs.map((x) => (x.id === subId ? { ...x, score, status: 'graded' as const } : x)),
    toGrade: s.toGrade - 1,                         // số đếm ở menu cập nhật ngay
  });
  try {
    await firstValueFrom(this.api.grade(subId, score));
  } catch (e) {
    this.patch({ subs: s.subs, toGrade: s.toGrade });  // hoàn tác về đúng ảnh chụp trước đó
    throw e;
  }
}

#NgRx SignalStore

NgRx (thư viện state phổ biến nhất của Angular) có SignalStore: gọn, dựa trên signals, có plugin cho entity, devtools, lưu localStorage. Gần với Pinia hơn NgRx Store cổ điển.

Terminal
npm install @ngrx/signals
class-store.ts (bản NgRx SignalStore)
import { patchState, signalStore, withComputed, withMethods, withState } from '@ngrx/signals';

export const ClassStore = signalStore(
  { providedIn: 'root' },
  withState({ items: [] as Classroom[], loading: false, query: '' }),
  withComputed(({ items, query }) => ({
    filtered: computed(() => items().filter((c) => c.name.toLowerCase().includes(query().toLowerCase()))),
    total: computed(() => items().length),
  })),
  withMethods((store, api = inject(ClassApi)) => ({
    setQuery(query: string) {
      patchState(store, { query });
    },
    async load() {
      patchState(store, { loading: true });
      const items = await firstValueFrom(api.list());
      patchState(store, { items, loading: false });
    },
  })),
);
TypeScript
store = inject(ClassStore);
// template: store.filtered(), store.loading(), store.setQuery('5A')

Mỗi trường trong withState tự trở thành signal chỉ đọc (store.items()), chỉ sửa được qua patchState bên trong method. Có withEntities cho danh sách có id, withHooks cho onInit / onDestroy, và rxMethod khi cần RxJS.

#NgRx Store cổ điển (Redux)

Ở dự án doanh nghiệp lâu năm, bạn sẽ gặp NgRx Store: action, reducer, selector, effect. Cần đọc được dòng chảy:

TypeScript
// actions
export const ClassActions = createActionGroup({
  source: 'Lớp',
  events: {
    'Tải': emptyProps(),
    'Tải thành công': props<{ items: Classroom[] }>(),
    'Tải thất bại': props<{ error: string }>(),
  },
});

// reducer
export const classesFeature = createFeature({
  name: 'classes',
  reducer: createReducer(
    { items: [] as Classroom[], loading: false },
    on(ClassActions.tải, (s) => ({ ...s, loading: true })),
    on(ClassActions.tảiThànhCông, (s, { items }) => ({ ...s, items, loading: false })),
  ),
});

// component
private store = inject(Store);
classes = this.store.selectSignal(classesFeature.selectItems);
ngOnInit() { this.store.dispatch(ClassActions.tải()); }

Đặt tên action bằng tiếng Anh ở dự án thật (ví dụ 'Load', 'Load Success'), ví dụ trên chỉ minh hoạ. NgRx Store mạnh ở ứng dụng rất lớn (lịch sử thay đổi, time-travel debug, quy ước chặt cho nhiều đội), nhưng nhiều chữ. Dự án mới cỡ vừa thường chọn service + signals hoặc SignalStore.

#Bài tập

Store chấm bài có cập nhật lạc quan

Viết GradingStore (service + signals) giữ danh sách bài nộp của một bài tập: tải danh sách, chấm điểm một bài (lạc quan, hoàn tác khi lỗi), số bài còn phải chấm, điểm trung bình. Viết component hiển thị và một ô nhập điểm cho mỗi bài. API giả trả lỗi khi điểm bằng 0 để thử hoàn tác.

Gợi ý từng bước

  1. State: signal<readonly Sub[]>, toGrade = computed(() => subs().filter(s => s.status === 'submitted').length).
  2. grade(id, score): lưu bản trước, cập nhật, gọi API, catch thì set lại bản trước và báo lỗi.
  3. Component chấm: providers: [GradingStore] nếu muốn mỗi trang một bản, hoặc providedIn root.
  4. Ô nhập điểm: (change)="store.grade(s.id, +$any($event.target).value)".
Xem lời giải
grading-store.ts
import { Injectable, computed, signal } from '@angular/core';

export interface Sub { id: number; student: string; status: 'submitted' | 'graded'; score: number | null }

const fakeApi = {
  grade: (id: number, score: number) =>
    new Promise<void>((ok, fail) => setTimeout(() => (score === 0 ? fail(new Error('Điểm 0 cần lý do')) : ok()), 500)),
};

@Injectable()
export class GradingStore {
  private readonly _subs = signal<readonly Sub[]>([
    { id: 1, student: 'An', status: 'submitted', score: null },
    { id: 2, student: 'Bình', status: 'submitted', score: null },
    { id: 3, student: 'Chi', status: 'graded', score: 8 },
  ]);
  readonly subs = this._subs.asReadonly();
  readonly error = signal<string | null>(null);
  readonly toGrade = computed(() => this._subs().filter((s) => s.status === 'submitted').length);
  readonly average = computed(() => {
    const g = this._subs().filter((s) => s.score != null);
    return g.length ? g.reduce((t, s) => t + s.score!, 0) / g.length : null;
  });

  async grade(id: number, score: number) {
    const before = this._subs();
    this.error.set(null);
    this._subs.set(before.map((s) => (s.id === id ? { ...s, score, status: 'graded' } : s)));
    try {
      await fakeApi.grade(id, score);
    } catch (e) {
      this._subs.set(before);
      this.error.set((e as Error).message);
    }
  }
}

}
