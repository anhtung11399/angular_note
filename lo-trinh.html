Angular nhìn từ mắt dân Vue

Angular là framework "đủ pin", khác Vue ở triết lý, cấu trúc và công cụ. Bảng đối chiếu tổng quát và cách học lộ trình này.

Học xong bài này bạn sẽ:
  • Hiểu Angular khác Vue ở đâu về triết lý và cấu trúc
  • Có bảng đối chiếu Vue → Angular trong đầu
  • Biết Angular hiện đại (standalone, signals, zoneless) khác Angular cũ thế nào

#Vue và Angular: hai triết lý

Bạn đã làm Vue 4 năm. Bạn biết component, reactivity, router, store, build tool. Tin tốt: khoảng 70% kiến thức đó dùng lại được. Angular không khó hơn Vue ở khái niệm, nó khác ở cách tổ chức và mức độ "đóng khung".

Hãy nghĩ Angular giống như Vue 3 + Vue Router + Pinia + VeeValidate + Axios + Vue I18n + Vitest + Nuxt, nhưng tất cả do một đội làm, cùng phong cách, cùng lịch phát hành, và CLI biết cách nâng cấp tất cả cùng lúc.

#Cùng một component, hai cách viết

Một bộ đếm có nút tăng, hiển thị số và "gấp đôi". Đây là thứ bạn viết mỗi ngày ở Vue:

Counter.vue
<script setup lang="ts">
import { ref, computed } from 'vue'

const props = defineProps<{ start: number }>()
const emit = defineEmits<{ changed: [value: number] }>()

const count = ref(props.start)
const double = computed(() => count.value * 2)

function inc() {
  count.value++
  emit('changed', count.value)
}
</script>

<template>
  <button @click="inc">Tăng</button>
  <p v-if="count > 0">{{ count }} × 2 = {{ double }}</p>
</template>

<style scoped>
button { font-weight: 600; }
</style>

Và đây là Angular hiện đại:

counter.ts
import { Component, computed, input, linkedSignal, output } from '@angular/core';

@Component({
  selector: 'app-counter',
  template: `
    <button (click)="inc()">Tăng</button>
    @if (count() > 0) {
      <p>{{ count() }} × 2 = {{ double() }}</p>
    }
  `,
  styles: `button { font-weight: 600; }`,
})
export class Counter {
  start = input.required<number>();       // defineProps
  changed = output<number>();             // defineEmits

  count = linkedSignal(() => this.start()); // ref, khởi tạo từ input
  double = computed(() => this.count() * 2);

  inc() {
    this.count.update((c) => c + 1);
    this.changed.emit(this.count());
  }
}
localhost:4200Minh hoạ

3 × 2 = 6

Nhìn kỹ, gần như mọi dòng đều có cặp tương ứng:

VueAngularKhác biệt
definePropsinput()input là một signal, đọc bằng start()
defineEmitsoutput()gọi .emit(giá trị)
ref(0), đọc .valuesignal(0), đọc bằng cách gọi hàm count()ghi bằng .set() / .update(), không gán trực tiếp
computedcomputedgiống hệt
@click="inc"(click)="inc()"ngoặc tròn cho event, phải có ()
v-if@if (...) { }khối riêng, không phải thuộc tính

Lỗi số một của dân Vue khi sang Angular: quên dấu () khi đọc signal trong template. Viết {{ count }} thì Angular in ra cả hàm signal (kiểu [Signal: 3]) thay vì số 3. Trong Vue, template tự "unwrap" ref, Angular thì không.

#Bức tranh một ứng dụng Angular

Ba thứ bạn sẽ thấy ở mọi dự án:

  • Component: giao diện. Nhận dữ liệu qua input(), báo sự kiện qua output(), giữ state cục bộ bằng signal.
  • Service: logic và dữ liệu dùng chung. Một class bình thường có @Injectable, Angular tạo và "tiêm" nó vào nơi cần qua inject(). Đây là chỗ bạn đặt những gì ở Vue bạn để trong composable hay store Pinia.
  • Dependency injection (DI): cơ chế Angular tự tạo đối tượng và đưa cho nơi cần. Bài 10 đi sâu, đây là khái niệm quan trọng nhất mà Vue không có tương đương đầy đủ (gần nhất là provide / inject).

#Angular cũ và Angular mới

Angular thay đổi rất nhiều từ bản 14 đến bản 20. Trên mạng (và trong dự án công ty) bạn sẽ gặp cả hai kiểu. Lộ trình này dạy kiểu mới, nhưng bạn phải đọc được kiểu cũ.

Ở các công ty Việt Nam, nhiều dự án Angular viết từ 2018 đến 2022 vẫn dùng NgModule và Zone.js, đang nâng cấp dần. Angular giữ tương thích rất tốt: code cũ và code mới chạy chung trong một ứng dụng. Nên bạn thường sẽ viết component mới theo kiểu mới, đặt cạnh component cũ.

#Những thứ sẽ làm bạn "khó chịu" lúc đầu

  1. Nhiều chữ hơn. Decorator, class, kiểu dữ liệu, import. Một component Angular thường dài hơn Vue 20 đến 30%. Đổi lại, đọc code của người khác rất dễ vì ai cũng viết giống nhau.
  2. RxJS. HttpClient trả Observable chứ không phải Promise. Bài 14 dạy đúng phần cần dùng. Với signals và httpResource, bạn ngày càng ít phải viết RxJS.
  3. Dependency injection. Lúc đầu thấy vòng vo ("sao không import rồi gọi luôn?"). Sau vài tuần, bạn sẽ thấy nó giúp test và thay thế cài đặt dễ như thế nào.
  4. Template nghiêm hơn. Template được biên dịch và kiểm tra kiểu: gõ sai tên thuộc tính là lỗi biên dịch, không phải lỗi lúc chạy.

#Lộ trình này dạy gì

Mỗi bài có: giải thích kèm hộp So với Vue, sơ đồ, code chạy được, khung kết quả hiển thị (minh hoạ giao diện), hộp Ngoài thực tế và Chuẩn production, câu hỏi nhanh và bài tập có lời giải.

Câu hỏi nhanh. Trong template Angular, signal name = signal('Lan') được hiển thị đúng bằng cách nào?

Signal là một hàm, đọc giá trị bằng cách gọi nó. Template Angular không tự unwrap như ref của Vue.

Câu hỏi nhanh. Ở Vue bạn đặt logic gọi API dùng chung trong composable useClasses(). Ở Angular, chỗ tương ứng thường là?

Service là nơi chứa logic và state dùng chung. Dependency injection tạo và chia sẻ nó.

#Bài tập

Dịch một component Vue sang Angular (trên giấy)

Chưa cần cài gì. Dịch component Vue sau sang Angular dựa vào bảng đối chiếu ở trên:

Greeting.vue
<script setup lang="ts">
import { ref, computed } from 'vue'
const props = defineProps<{ firstName: string }>()
const shout = ref(false)
const text = computed(() => `Xin chào, ${props.firstName}` + (shout.value ? '!!!' : '.'))
</script>

<template>
  <label><input type="checkbox" v-model="shout" /> Hét lên</label>
  <h2>{{ text }}</h2>
</template>

Gợi ý từng bước

  1. defineProps → firstName = input.required<string>().
  2. ref(false) → shout = signal(false).
  3. Trong computed, đọc input và signal bằng cách gọi hàm: this.firstName(), this.shout().
  4. v-model trên checkbox: chưa học forms, dùng [checked]="shout()" và (change)="shout.set($any($event.target).checked)". Bài 4 sẽ chỉ cách gọn hơn.
Xem lời giải
greeting.ts
import { Component, computed, input, signal } from '@angular/core';

@Component({
  selector: 'app-greeting',
  template: `
    <label>
      <input type="checkbox" [checked]="shout()" (change)="toggle($event)" /> Hét lên
    </label>
    <h2>{{ text() }}</h2>
  `,
})
export class Greeting {
  firstName = input.required<string>();
  shout = signal(false);
  text = computed(() => `Xin chào, ${this.firstName()}` + (this.shout() ? '!!!' : '.'));

  toggle(e: Event) {
    this.shout.set((e.target as HTMLInputElement).checked);
  }
}
app.html (nơi dùng)
<app-greeting firstName="Lan" />
localhost:4200Minh hoạ

Xin chào, Lan!!!

Giải thích: firstName="Lan" truyền chuỗi tĩnh. Nếu muốn truyền biến thì viết [firstName]="ten()" (ngoặc vuông = binding, giống :firstName của Vue). Ép kiểu e.target as HTMLInputElement là cách TypeScript bắt buộc: Angular kiểm tra kiểu cả trong template.
