Control flow: @if, @for, @switch, @defer

Cú pháp khối mới thay cho *ngIf / *ngFor, track bắt buộc, @empty, @defer với các trigger. So với v-if, v-for, Suspense / async component.

Học xong bài này bạn sẽ:
  • Dùng @if / @for / @switch thành thạo
  • Chọn khoá track đúng
  • Trì hoãn tải phần giao diện nặng bằng @defer

#Khối điều khiển thay cho directive

Từ Angular 17, template có khối điều khiển (built-in control flow) bắt đầu bằng @. Chúng không phải thuộc tính gắn lên thẻ như v-if, mà là khối bao quanh nội dung:

Template
<!-- Vue -->
<p v-if="loading">Đang tải…</p>
<p v-else-if="error">{{ error }}</p>
<ul v-else>
  <li v-for="a in assignments" :key="a.id">{{ a.title }}</li>
</ul>
Template
<!-- Angular -->
@if (loading()) {
  <p>Đang tải…</p>
} @else if (error()) {
  <p>{{ error() }}</p>
} @else {
  <ul>
    @for (a of assignments(); track a.id) {
      <li>{{ a.title }}</li>
    }
  </ul>
}

Khối không sinh thẻ HTML nào, giống <template v-if> của Vue. Không cần import gì.

#@if

Template
@if (user(); as u) {
  <p>Xin chào {{ u.name }}</p>          <!-- u chắc chắn khác null trong khối này -->
} @else {
  <a routerLink="/dang-nhap">Đăng nhập</a>
}

@if (assignments().length === 0) {
  <app-empty-state>Chưa có bài tập nào</app-empty-state>
}

as u lưu kết quả biểu thức vào biến, đồng thời thu hẹp kiểu: bên trong khối, TypeScript biết u không phải null.

#@for và track

Template
<ul>
  @for (a of assignments(); track a.id; let i = $index, last = $last) {
    <li [class.late]="a.late">
      {{ i + 1 }}. {{ a.title }}
      @if (!last) { <hr /> }
    </li>
  } @empty {
    <li class="muted">Chưa có bài tập</li>
  }
</ul>
BiếnÝ nghĩa
$indexvị trí (từ 0)
$counttổng số phần tử
$first, $lastphần tử đầu / cuối
$even, $oddchẵn / lẻ (tô màu xen kẽ)

@empty hiển thị khi danh sách rỗng, thay cho cặp v-if="list.length === 0" riêng.

track là bắt buộc

Khác Vue (nơi :key chỉ là khuyến nghị và có cảnh báo), track trong Angular bắt buộc, thiếu là lỗi biên dịch. Nó cho Angular biết phần tử nào là phần tử nào khi danh sách đổi, để giữ DOM cũ thay vì xoá đi tạo lại.

Dữ liệuNên track
Object có id từ APItrack a.id
Mảng chuỗi / số không trùngtrack tag (chính giá trị)
Mảng có thể trùng giá trị, không bao giờ sắp xếp lạitrack $index
Object không có id, được giữ nguyên tham chiếutrack a (theo tham chiếu)

track $index nghe tiện nhưng sai khi danh sách được thêm / xoá / sắp xếp: Angular sẽ gắn nhầm DOM của phần tử cũ cho phần tử mới (ví dụ ô nhập điểm của em An hiện giá trị của em Bình sau khi xoá một em ở đầu). Có id thì luôn track theo id.

#@switch

Template
@switch (submission().status) {
  @case ('missing') { <span class="tag red">Chưa nộp</span> }
  @case ('submitted') { <span class="tag blue">Chờ chấm</span> }
  @case ('graded') { <span class="tag green">{{ submission().score }} điểm</span> }
  @default { <span class="tag">Không rõ</span> }
}

So sánh bằng ===, không "rơi" xuống case dưới (không cần break). Vue không có v-switch, bạn hay viết chuỗi v-if / v-else-if: ở Angular dùng @switch gọn hơn.

#@defer: tải lười một phần giao diện

@defer tách nội dung (và mọi component, directive, pipe bên trong) thành một chunk JavaScript riêng, chỉ tải khi điều kiện xảy ra. Đây là thứ Vue làm bằng defineAsyncComponent + <Suspense>, nhưng Angular làm bằng cú pháp template, không cần sửa code TypeScript.

Template
<h2>Kết quả lớp 5A</h2>
<app-summary [data]="summary()" />

@defer (on viewport) {
  <app-score-chart [scores]="scores()" />        <!-- thư viện vẽ biểu đồ nặng 200 KB -->
} @placeholder (minimum 300ms) {
  <div class="chart-skeleton"></div>             <!-- hiện trước khi bắt đầu tải -->
} @loading (after 150ms; minimum 500ms) {
  <app-spinner />                                <!-- hiện trong lúc tải -->
} @error {
  <p>Không tải được biểu đồ. <button (click)="reload()">Thử lại</button></p>
}
TriggerTải khi
on idle (mặc định)trình duyệt rảnh (requestIdleCallback)
on viewportplaceholder lọt vào màn hình
on interactionngười dùng click / gõ vào placeholder
on hoverrê chuột vào placeholder
on timer(2s)sau một khoảng thời gian
on immediatengay khi phần còn lại render xong
when điềuKiện()khi biểu thức thành true (một lần)
prefetch on idletải trước (chưa hiển thị), ví dụ @defer (on interaction; prefetch on idle)

Component bên trong @defer chỉ được tách chunk nếu nó không được dùng ở chỗ khác ngoài khối defer trong cùng file (kể cả không được tham chiếu trong code TypeScript của component). Nếu bạn lỡ dùng viewChild(ScoreChart), nó bị kéo vào bundle chính và @defer mất tác dụng tách code.

Ứng dụng có SSR: @defer còn dùng cho incremental hydration (hydrate on viewport), bài 20.

#Đọc template cũ: *ngIf, *ngFor

Dự án trước v17 viết bằng structural directive (dấu sao). Bạn cần đọc được:

Template
<!-- Cũ -->
<p *ngIf="loading; else ready">Đang tải…</p>
<ng-template #ready>
  <li *ngFor="let a of assignments; trackBy: trackById; let i = index">{{ i + 1 }}. {{ a.title }}</li>
</ng-template>

<div [ngSwitch]="status">
  <span *ngSwitchCase="'graded'">Đã chấm</span>
  <span *ngSwitchDefault>Chưa chấm</span>
</div>

<!-- Mới -->
@if (loading) {
  <p>Đang tải…</p>
} @else {
  @for (a of assignments; track a.id; let i = $index) { <li>{{ i + 1 }}. {{ a.title }}</li> }
}
Terminal
ng generate @angular/core:control-flow   # tự chuyển *ngIf / *ngFor / ngSwitch sang cú pháp mới

Dấu * là cú pháp rút gọn: Angular bọc phần tử vào một <ng-template> rồi để directive quyết định có render template đó không. Bạn vẫn sẽ thấy dấu sao ở các directive cấu trúc khác như *ngTemplateOutlet, *cdkVirtualFor.

Câu hỏi nhanh. Viết @for (a of list(); track $index) cho danh sách học sinh có thể xoá phần tử ở giữa. Vấn đề gì có thể xảy ra?

track theo vị trí khiến Angular coi "phần tử thứ 2" là cùng một phần tử dù dữ liệu đã dịch chuyển. Có id thì track theo id.

Câu hỏi nhanh. Biểu đồ nặng ở cuối trang, muốn chỉ tải code khi người dùng cuộn tới. Dùng gì?

@if chỉ ẩn / hiện, code vẫn nằm trong bundle ban đầu. @defer tách thành chunk riêng và tải lười.

#Bài tập

Bảng điểm có lọc, trạng thái rỗng và phần thống kê tải lười

Viết component hiển thị danh sách bài nộp: mỗi dòng có số thứ tự, tên học sinh, trạng thái (dùng @switch), dòng chẵn tô nền nhạt. Có nút lọc "Chỉ chưa nộp". Khi danh sách lọc rỗng hiện "Tất cả đã nộp". Phần thống kê (component Stats) chỉ tải khi người dùng bấm vào khung "Xem thống kê".

Gợi ý từng bước

  1. Dữ liệu: signal chứa mảng 5 bài nộp, onlyMissing = signal(false), shown = computed(...) lọc theo cờ.
  2. @for (s of shown(); track s.id; let i = $index, even = $even), gắn [class.even]="even".
  3. @empty cho trường hợp rỗng.
  4. @defer (on interaction) { <app-stats [subs]="subs()" /> } @placeholder { <button>Xem thống kê</button> }.
Xem lời giải
submission-table.ts
import { Component, computed, signal } from '@angular/core';
import { Stats } from './stats';

interface Sub { id: number; name: string; status: 'missing' | 'submitted' | 'graded'; score?: number }

@Component({
  selector: 'app-submission-table',
  imports: [Stats],
  template: `
    <label><input type="checkbox" [checked]="onlyMissing()" (change)="onlyMissing.set(!onlyMissing())" /> Chỉ chưa nộp</label>
    <ol>
      @for (s of shown(); track s.id; let i = $index, even = $even) {
        <li [class.even]="even">
          <b>{{ i + 1 }}.</b> {{ s.name }} —
          @switch (s.status) {
            @case ('missing') { <span class="red">Chưa nộp</span> }
            @case ('submitted') { <span class="blue">Chờ chấm</span> }
            @case ('graded') { <span class="green">{{ s.score }} điểm</span> }
          }
        </li>
      } @empty {
        <li>Tất cả đã nộp 🎉</li>
      }
    </ol>

    @defer (on interaction) {
      <app-stats [subs]="subs()" />
    } @placeholder {
      <button>Xem thống kê</button>
    } @loading (minimum 300ms) {
      <p>Đang tải thống kê…</p>
    }
  `,
  styles: `.even { background: #f8fafc; } .red { color: #dc2626; } .blue { color: #2563eb; } .green { color: #16a34a; }`,
})
export class SubmissionTable {
  protected subs = signal<Sub[]>([
    { id: 1, name: 'An', status: 'graded', score: 9 },
    { id: 2, name: 'Bình', status: 'missing' },
    { id: 3, name: 'Chi', status: 'submitted' },
    { id: 4, name: 'Dũng', status: 'graded', score: 7 },
    { id: 5, name: 'Hà', status: 'missing' },
  ]);
  protected onlyMissing = signal(false);
  protected shown = computed(() => (this.onlyMissing() ? this.subs().filter((s) => s.status === 'missing') : this.subs()));
}
stats.ts
import { Component, computed, input } from '@angular/core';

@Component({
  selector: 'app-stats',
  template: `<p>Đã nộp {{ done() }}/{{ subs().length }} · điểm trung bình {{ avg() }}</p>`,
})
export class Stats {
  subs = input.required<{ status: string; score?: number }[]>();
  protected done = computed(() => this.subs().filter((s) => s.status !== 'missing').length);
  protected avg = computed(() => {
    const g = this.subs().filter((s) => s.score != null);
    return g.length ? (g.reduce((t, s) => t + s.score!, 0) / g.length).toFixed(1) : '—';
  });
}
