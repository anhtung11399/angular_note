Router

Routes, lazy loading, tham số qua input, guard dạng hàm, resolver, route con, chuyển trang bằng code. So với vue-router.

Học xong bài này bạn sẽ:
  • Cấu hình router với lazy loading
  • Bảo vệ route bằng guard
  • Nhận tham số route vào component qua input

#Khai báo route

app.routes.ts
import { Routes } from '@angular/router';
import { Home } from './home';
import { authGuard } from './core/auth.guard';

export const routes: Routes = [
  { path: '', component: Home, title: 'Trang chủ' },
  { path: 'dang-nhap', loadComponent: () => import('./core/login-page').then((m) => m.LoginPage), title: 'Đăng nhập' },
  {
    path: 'lop',
    canActivate: [authGuard],
    loadChildren: () => import('./features/classes/classes.routes').then((m) => m.CLASS_ROUTES),
  },
  { path: 'cu', redirectTo: 'lop', pathMatch: 'full' },
  { path: '**', loadComponent: () => import('./not-found').then((m) => m.NotFound), title: 'Không tìm thấy' },
];

#Bật router và các tuỳ chọn

app.config.ts
import { provideRouter, withComponentInputBinding, withInMemoryScrolling, withViewTransitions, withPreloading, PreloadAllModules } from '@angular/router';

providers: [
  provideRouter(
    routes,
    withComponentInputBinding(),                     // tham số route → input của component
    withInMemoryScrolling({ scrollPositionRestoration: 'enabled', anchorScrolling: 'enabled' }),
    withViewTransitions(),                           // hiệu ứng chuyển trang bằng View Transitions API
    withPreloading(PreloadAllModules),               // tải trước các route lazy khi rảnh
  ),
]

openClass(id: number) {

#Nhận tham số route bằng input

Với withComponentInputBinding(), tham số đường dẫn, query param và data của route được gán thẳng vào input cùng tên:

grading-page.ts
export class GradingPage {
  classId = input.required<string>();          // từ :classId của route cha (cần paramsInheritanceStrategy: 'always')
  mon = input<string>();                        // từ ?mon=toan
  em = input<string>();                         // từ ?em=7

  subject = computed(() => this.mon() ?? 'toan');
}

Tham số luôn là chuỗi. Dùng transform: numberAttribute nếu cần số: classId = input.required({ transform: numberAttribute }). Vì input là signal, khi URL đổi từ /lop/1 sang /lop/2, mọi computed và httpResource dựa trên nó tự chạy lại.

cách cũ, vẫn gặp nhiều
private route = inject(ActivatedRoute);
classId$ = this.route.paramMap.pipe(map((p) => Number(p.get('classId'))));
// hoặc ảnh chụp một lần (SAI khi tham số đổi mà component được giữ lại):
id = Number(this.route.snapshot.paramMap.get('classId'));

#Guard dạng hàm

core/auth.guard.ts
import { CanActivateFn, Router } from '@angular/router';

export const authGuard: CanActivateFn = (route, state) => {
  const auth = inject(Auth);
  if (auth.isLoggedIn()) return true;
  // trả về UrlTree = chuyển hướng (không gọi navigate trong guard)
  return inject(Router).createUrlTree(['/dang-nhap'], { queryParams: { next: state.url } });
};

export const teacherOnly: CanMatchFn = () => inject(Auth).isTeacher();

#Resolver: tải dữ liệu trước khi vào trang

TypeScript
export const classResolver: ResolveFn<Classroom> = (route) =>
  inject(ClassApi).get(Number(route.paramMap.get('classId')));

{ path: ':classId', resolve: { classroom: classResolver }, loadComponent: ... }

// component nhận qua input cùng tên (với withComponentInputBinding)
classroom = input.required<Classroom>();

Resolver khiến router đợi dữ liệu rồi mới hiện trang: người dùng thấy như bấm không ăn vài trăm mili giây. Xu hướng hiện nay: vào trang ngay, hiện khung xương (skeleton) và tải bằng httpResource (bài 13). Dùng resolver khi trang không có ý nghĩa nếu thiếu dữ liệu (và khi SSR cần dữ liệu đầy đủ).

#Bài tập

Khu vực lớp học có menu con, guard và trang 404

Dựng router cho: / trang chủ, /lop danh sách lớp (cần đăng nhập), /lop/:classId/bai-tap và /lop/:classId/hoc-sinh dùng chung layout có menu hai mục và tiêu đề "Lớp {{ classId }}", mọi URL khác vào trang 404. Đăng nhập giả bằng một signal trong service Auth.

Gợi ý từng bước

  1. provideRouter(routes, withComponentInputBinding()) và trong provideRouter thêm withRouterConfig({ paramsInheritanceStrategy: 'always' }) để route con nhận classId của cha.
  2. Route lop/:classId có component: ClassLayout và children.
  3. ClassLayout: input classId, template có hai routerLink tương đối và <router-outlet />.
  4. Guard: inject(Auth).loggedIn() || inject(Router).createUrlTree(['/']).
Xem lời giải
app.routes.ts
export const routes: Routes = [
  { path: '', component: Home, title: 'Trang chủ' },

    path: 'lop',
    canActivate: [() => inject(Auth).loggedIn() || inject(Router).createUrlTree(['/'])],
