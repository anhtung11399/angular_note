Directive và pipe

Attribute directive, host binding, directive composition, pipe có sẵn và pipe tự viết, pure / impure. So với custom directive và filter của Vue 2.

Học xong bài này bạn sẽ:
  • Viết attribute directive dùng lại được
  • Dùng và tự viết pipe
  • Biết khi nào dùng directive, khi nào dùng component

#Directive: hành vi gắn lên phần tử có sẵn

Component = directive có template. Attribute directive không có template, nó thêm hành vi cho phần tử mà nó được gắn vào: tự focus, tooltip, kéo thả, kiểm tra quyền, tự co giãn textarea.

Tương đương custom directive của Vue (v-focus, app.directive('focus', ...)). Khác: directive Angular là class đầy đủ, có input, output, inject service, signal, và phải được khai báo trong imports như component.

shared/autofocus.ts
import { Directive, ElementRef, afterNextRender, inject, input } from '@angular/core';

@Directive({
  selector: '[appAutofocus]',   // gắn bằng thuộc tính
})
export class Autofocus {
  private el = inject<ElementRef<HTMLElement>>(ElementRef);
  enabled = input(true, { alias: 'appAutofocus', transform: (v: boolean | '') => v !== false });

  constructor() {
    afterNextRender(() => {
      if (this.enabled()) this.el.nativeElement.focus();
    });
  }
}
dùng
<input appAutofocus placeholder="Tên lớp" />
<input [appAutofocus]="isNew()" />

#host: binding và listener trên phần tử chủ

shared/auto-grow.ts
@Directive({
  selector: 'textarea[appAutoGrow]',          // chỉ áp cho textarea có thuộc tính này
  host: {
    '(input)': 'resize()',                    // lắng nghe sự kiện trên phần tử
    '[style.overflow]': '"hidden"',           // gán style
    '[attr.rows]': 'minRows()',
  },
})
export class AutoGrow {
  private el = inject<ElementRef<HTMLTextAreaElement>>(ElementRef);
  minRows = input(2);

  constructor() {
    afterNextRender(() => this.resize());
  }

  protected resize() {
    const t = this.el.nativeElement;
    t.style.height = 'auto';
    t.style.height = t.scrollHeight + 'px';
  }
}
Template
<textarea appAutoGrow [minRows]="3" placeholder="Nhận xét"></textarea>

host trong metadata là cách hiện đại thay cho @HostBinding / @HostListener (vẫn gặp trong code cũ):

TypeScript
// Kiểu cũ
@HostListener('input') onInput() { this.resize(); }
@HostBinding('style.overflow') overflow = 'hidden';

#Directive có output và nhận dữ liệu

shared/click-outside.ts
@Directive({
  selector: '[appClickOutside]',
  host: { '(document:click)': 'onDocClick($event)' },
})
export class ClickOutside {
  private el = inject(ElementRef);
  appClickOutside = output<void>();

  protected onDocClick(e: MouseEvent) {
    if (!this.el.nativeElement.contains(e.target)) this.appClickOutside.emit();
  }
}
Template
<div class="menu" (appClickOutside)="menuOpen.set(false)">...</div>

#Directive kiểm tra quyền (structural directive)

Muốn ẩn hẳn một phần giao diện theo quyền, có thể viết directive cấu trúc (dạng *) tạo / huỷ template:

core/if-role.ts
import { Directive, TemplateRef, ViewContainerRef, effect, inject, input } from '@angular/core';
import { Auth } from './auth';

@Directive({ selector: '[appIfRole]' })
export class IfRole {
  private tpl = inject(TemplateRef);
  private vcr = inject(ViewContainerRef);
  private auth = inject(Auth);
  appIfRole = input.required<'teacher' | 'parent'>();

  constructor() {
    effect(() => {
      this.vcr.clear();
      if (this.auth.role() === this.appIfRole()) this.vcr.createEmbeddedView(this.tpl);
    });
  }
}
Template
<button *appIfRole="'teacher'">Giao bài mới</button>

Ẩn nút theo quyền chỉ là trải nghiệm người dùng, không phải bảo mật. Người dùng mở DevTools vẫn gọi được API. Server luôn phải kiểm tra quyền (bài 22).

Với code mới, nhiều đội thích viết @if (auth.isTeacher()) { ... } trực tiếp hơn là viết directive cấu trúc: rõ ràng hơn, không cần học cơ chế TemplateRef. Viết directive khi cùng một logic lặp lại ở rất nhiều chỗ.

#Directive composition: ghép directive vào component

TypeScript
@Component({
  selector: 'app-menu-button',
  hostDirectives: [
    ClickOutside,
    { directive: Tooltip, inputs: ['tooltip'] },   // mở input tooltip ra ngoài
  ],
  template: `...`,
})
export class MenuButton {}

hostDirectives gắn sẵn các directive vào component, người dùng component không cần thêm thuộc tính. Giống trộn composable vào component ở Vue, nhưng ở mức hành vi DOM.

#Pipe: biến đổi giá trị để hiển thị

Template
<p>{{ dueDate | date: 'EEEE, dd/MM/yyyy' }}</p>       <!-- Thứ Ba, 10/11/2026 (khi đặt locale vi) -->
<p>{{ price | currency: 'VND' : 'symbol' : '1.0-0' }}</p>  <!-- 49.000 ₫ -->
<p>{{ ratio | percent: '1.0-1' }}</p>                  <!-- 83,3% -->
<p>{{ average | number: '1.1-2' }}</p>                 <!-- 8,25 -->
<p>{{ name | uppercase }}</p>
<pre>{{ debugObject | json }}

{{ list | slice: 0 : 3 }}

{{ data$ | async }}

Pipe nhận tham số sau dấu :, nối được nhiều pipe: {{ name | slice:0:20 | uppercase }}. Mỗi pipe phải được import vào component (DatePipe, CurrencyPipe, DecimalPipe, PercentPipe, AsyncPipe...).

Vue 2 có filter ({{ price | currency }}), Vue 3 bỏ filter và khuyên dùng method / computed. Angular vẫn giữ pipe vì pure pipe được ghi nhớ: chỉ chạy lại khi tham số đổi, nên dùng trong template an toàn về hiệu năng hơn gọi method.

Định dạng theo tiếng Việt

app.config.ts
import { LOCALE_ID } from '@angular/core';
import { registerLocaleData } from '@angular/common';
import localeVi from '@angular/common/locales/vi';

registerLocaleData(localeVi);

export const appConfig: ApplicationConfig = {
  providers: [
    { provide: LOCALE_ID, useValue: 'vi' },
    { provide: DEFAULT_CURRENCY_CODE, useValue: 'VND' },
  ],
};

Sau đó {{ 49000 | currency }} ra "49.000 ₫", {{ d | date:'fullDate' }} ra "Thứ Ba, 10 tháng 11, 2026".

Tự viết pipe

shared/relative-due.ts
import { Pipe, PipeTransform } from '@angular/core';

@Pipe({ name: 'relativeDue' })   // pure: true là mặc định
export class RelativeDuePipe implements PipeTransform {
  transform(due: string, today = new Date().toISOString().slice(0, 10)): string {
    const days = Math.round((Date.parse(due) - Date.parse(today)) / 86_400_000);
    if (days < 0) return `Quá hạn ${-days} ngày`;
    if (days === 0) return 'Hạn hôm nay';
    if (days === 1) return 'Hạn ngày mai';
    return `Còn ${days} ngày`;
  }
}
Template
@for (a of assignments(); track a.id) {
  <li>{{ a.title }} — <span [class.late]="a.dueDate < today">{{ a.dueDate | relativeDue: today }}</span></li>
}

Pure và impure

Pure (mặc định)Impure (pure: false)
Chạy lại khitham số đổi (so sánh tham chiếu)mỗi lần Angular kiểm tra giao diện
Mảng bị push tại chỗkhông chạy lại (tham chiếu không đổi)chạy lại
Hiệu năngtốttốn, tránh dùng

Với dữ liệu bất biến (luôn tạo mảng mới như signal yêu cầu), pure pipe luôn đúng. Đó là lý do bạn hầu như không cần impure pipe.

Pipe hay computed? Pipe khi phép biến đổi dùng lại ở nhiều template (định dạng ngày, tiền, "còn N ngày"). computed khi logic thuộc riêng về một component.

Câu hỏi nhanh. Directive cần nghe sự kiện click trên toàn trang để đóng menu. Cách viết hiện đại?

host listener được Angular tự gỡ khi directive bị huỷ. @HostListener vẫn chạy nhưng là cú pháp cũ.

Câu hỏi nhanh. Pure pipe count trên mảng items(), và code gọi items().push(x). Con số hiển thị?

Luôn tạo mảng mới: items.update(l => [...l, x]).

#Bài tập

Directive appHighlight và pipe initials

Viết directive appHighlight tô nền phần tử khi rê chuột (màu truyền qua input, mặc định vàng nhạt). Viết pipe initials đổi "Nguyễn Thị Lan" thành "NL" (chữ đầu của họ và tên cuối). Dùng cả hai trong danh sách học sinh hiển thị avatar chữ tròn.

Gợi ý từng bước

  1. Directive: color = input('#fef9c3', { alias: 'appHighlight' }), hovering = signal(false).
  2. host: { '(mouseenter)': 'hovering.set(true)', '(mouseleave)': 'hovering.set(false)', '[style.background]': 'hovering() ? color() : null' }.
  3. Pipe: tách chuỗi bằng trim().split(/\s+/), lấy chữ đầu của phần tử đầu và cuối, viết hoa.
  4. Nhớ import cả directive và pipe vào component dùng chúng.
Xem lời giải
highlight.ts
import { Directive, input, signal } from '@angular/core';

@Directive({
  selector: '[appHighlight]',
  host: {
    '(mouseenter)': 'hovering.set(true)',
    '(mouseleave)': 'hovering.set(false)',
    '[style.background]': 'hovering() ? color() : null',
  },
})
export class Highlight {
  color = input('#fef9c3', { alias: 'appHighlight', transform: (v: string) => v || '#fef9c3' });
  protected hovering = signal(false);
}
initials.pipe.ts
import { Pipe, PipeTransform } from '@angular/core';

@Pipe({ name: 'initials' })
export class InitialsPipe implements PipeTransform {
  transform(fullName: string | null | undefined): string {
    const parts = (fullName ?? '').trim().split(/\s+/).filter(Boolean);
    if (!parts.length) return '?';
    const first = parts[0][0];
    const last = parts.length > 1 ? parts[parts.length - 1][0] : '';
    return (first + last).toLocaleUpperCase('vi');
  }
}
roster.ts
@Component({
  selector: 'app-roster',
  imports: [Highlight, InitialsPipe],
  template: `
    @for (s of students; track s.id) {
      <div class="row" appHighlight>
        <span class="avatar">{{ s.name | initials }}</span> {{ s.name }}
      </div>
    }
  `,
  styles: `.row { display: flex; align-items: center; gap: 10px; padding: 6px 8px; border-radius: 8px; }
           .avatar { width: 32px; height: 32px; border-radius: 50%; display: grid; place-items: center; background: #dd0031; color: #fff; font-weight: 700; font-size: 13px; }`,
})
export class Roster {
  protected students = [{ id: 1, name: 'Nguyễn Thị Lan' }, { id: 2, name: 'Trần Bình' }, { id: 3, name: 'Ánh' }];
}
