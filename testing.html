Kiểm thử

Vitest / Jasmine với TestBed, test component, test service có HTTP giả, component harness, test e2e bằng Playwright. So với Vitest + Vue Test Utils.

Học xong bài này bạn sẽ:
  • Viết unit test cho component và service
  • Giả lập HTTP trong test
  • Viết test e2e cho luồng chính

    expect(pipe.transform(due, '2026-11-04')).toBe(expected);
  });
});

#Test service có inject: TestBed

class-store.spec.ts
import { TestBed } from '@angular/core/testing';
import { of, throwError } from 'rxjs';

describe('ClassStore', () => {
  let store: ClassStore;
  const api = {
    list: vi.fn(() => of([{ id: 1, name: 'Lớp 5A', students: 30 }])),
    update: vi.fn(() => of({})),
  };

  beforeEach(() => {
    vi.clearAllMocks();
    TestBed.configureTestingModule({
      providers: [{ provide: ClassApi, useValue: api }],   // thay API thật bằng bản giả
    });
    store = TestBed.inject(ClassStore);
  });

  it('tải danh sách lớp', async () => {
    await store.load();
    expect(store.items().map((c) => c.name)).toEqual(['Lớp 5A']);
    expect(store.totalStudents()).toBe(30);
  });

  it('đổi tên lỗi thì hoàn tác', async () => {
    await store.load();
    api.update.mockReturnValueOnce(throwError(() => new Error('500')));
    await store.rename(1, 'Lớp 5A1');
    expect(store.items()[0].name).toBe('Lớp 5A');
    expect(store.error()).toContain('không thành công');
  });
});

Đây là chỗ DI phát huy: thay ClassApi bằng object giả qua providers, không cần vi.mock('../api') cấp module như ở Vue. Store không biết và không cần biết mình đang dùng API thật hay giả.

#Test HTTP thật sự: HttpTestingController

assignment-api.spec.ts
import { provideHttpClient } from '@angular/common/http';
import { HttpTestingController, provideHttpClientTesting } from '@angular/common/http/testing';
import { firstValueFrom } from 'rxjs';

describe('AssignmentApi', () => {
  let api: AssignmentApi;
  let http: HttpTestingController;

  beforeEach(() => {
    TestBed.configureTestingModule({ providers: [provideHttpClient(), provideHttpClientTesting()] });
    api = TestBed.inject(AssignmentApi);
    http = TestBed.inject(HttpTestingController);
  });

  afterEach(() => http.verify());   // báo lỗi nếu còn request chưa được xử lý

  it('gửi classId và page dạng query', async () => {
    const result = firstValueFrom(api.list(5, 2));
    const req = http.expectOne((r) => r.url === '/api/assignments');
    expect(req.request.params.get('classId')).toBe('5');
    expect(req.request.params.get('page')).toBe('2');
    req.flush({ items: [], page: 2, totalPages: 3 });       // trả response giả
    expect((await result).totalPages).toBe(3);
  });

  it('báo lỗi 404', async () => {
    const result = firstValueFrom(api.get(99));
    http.expectOne('/api/assignments/99').flush({ error: { code: 'NOT_FOUND' } }, { status: 404, statusText: 'Not Found' });
    await expect(result).rejects.toMatchObject({ status: 404 });
  });
});

#Test component

rating.spec.ts
import { ComponentFixture, TestBed } from '@angular/core/testing';

describe('Rating', () => {
  let fixture: ComponentFixture<Rating>;
  let el: HTMLElement;

  beforeEach(async () => {
    await TestBed.configureTestingModule({ imports: [Rating] }).compileComponents(); // component standalone: đưa vào imports
    fixture = TestBed.createComponent(Rating);
    fixture.componentRef.setInput('value', 2);     // đặt input
    await fixture.whenStable();                    // chờ render (zoneless)
    el = fixture.nativeElement;
  });

  it('hiện đúng số sao đang chọn', () => {
    expect(el.querySelectorAll('button.on').length).toBe(2);
  });

  it('bấm sao thứ 4 thì cập nhật model và giao diện', async () => {
    const buttons = el.querySelectorAll<HTMLButtonElement>('button');
    buttons[3].click();
    await fixture.whenStable();
    expect(fixture.componentInstance.value()).toBe(4);
    expect(el.querySelectorAll('button.on').length).toBe(4);
  });
});

Ba thao tác cơ bản: setInput để truyền input, thao tác DOM (click(), đặt value rồi dispatchEvent(new Event('input'))), rồi await fixture.whenStable() trước khi kiểm tra DOM.

Với dự án dùng Zone.js, bạn sẽ thấy fixture.detectChanges() gọi khắp nơi, cùng fakeAsync / tick(). Với zoneless, await fixture.whenStable() là cách chính, và đồng hồ giả dùng vi.useFakeTimers() của Vitest.

Test output và component có service

it('bấm Xoá phát output remove với bài tập', async () => {

#Bao nhiêu test là đủ

Ưu tiên testVì sao
Store / service chứa logic nghiệp vụnhiều nhánh, dễ test, lỗi ở đây ảnh hưởng nhiều màn hình
Pipe, validator, hàm tiện íchthuần, test rất rẻ
Component có logic tương tác phức tạp (form động, bảng chấm điểm)lỗi tương tác khó thấy bằng mắt
Vài luồng E2E quan trọng nhất (đăng nhập, giao bài, nộp bài, thanh toán)bắt lỗi tích hợp mà unit test bỏ qua
Ít ưu tiên: component chỉ hiển thịthay đổi thường xuyên, giá trị test thấp

Câu hỏi nhanh. Test component zoneless: bấm nút rồi kiểm tra DOM ngay thì chưa thấy thay đổi. Cần thêm gì?

Ứng dụng zoneless lập lịch render bất đồng bộ. whenStable chờ cho tới khi Angular render xong.

Câu hỏi nhanh. Cách đúng để test service gọi API mà không gửi request thật?

HttpTestingController chặn mọi request, cho bạn kiểm tra URL / body và trả response giả.

#Bài tập

Test cho ConfirmDialog

Viết test cho ConfirmDialog ở bài 7: (1) khi open là false thì không có hộp thoại, (2) bấm "Huỷ" thì open thành false và không phát confirmed, (3) bấm nút xác nhận thì phát confirmed đúng một lần, (4) bấm Escape thì đóng.

Gợi ý từng bước

  1. fixture.componentRef.setInput('open', true) và setInput('title', 'Xoá?') (model nhận input như input thường).
  2. Theo dõi output: fixture.componentInstance.confirmed.subscribe(spy).
  3. Escape: document.dispatchEvent(new KeyboardEvent('keydown', { key: 'Escape' })).
  4. Sau mỗi thao tác: await fixture.whenStable().
Xem lời giải
confirm-dialog.spec.ts
import { TestBed, ComponentFixture } from '@angular/core/testing';
import { ConfirmDialog } from './confirm-dialog';

describe('ConfirmDialog', () => {
  let fixture: ComponentFixture<ConfirmDialog>;
  const q = (sel: string) => fixture.nativeElement.querySelector(sel) as HTMLElement | null;
  const buttons = () => Array.from(fixture.nativeElement.querySelectorAll('button')) as HTMLButtonElement[];

  beforeEach(async () => {
    TestBed.configureTestingModule({ imports: [ConfirmDialog] });
    fixture = TestBed.createComponent(ConfirmDialog);
    fixture.componentRef.setInput('title', 'Xoá bài?');
    fixture.componentRef.setInput('open', true);
    await fixture.whenStable();
  });

  it('đóng thì không có hộp thoại', async () => {
    fixture.componentRef.setInput('open', false);
    await fixture.whenStable();
    expect(q('[role=dialog]')).toBeNull();
  });

  it('Huỷ: đóng và không phát confirmed', async () => {
    const spy = vi.fn();
    fixture.componentInstance.confirmed.subscribe(spy);
    buttons().find((b) => b.textContent?.includes('Huỷ'))!.click();
    await fixture.whenStable();
    expect(fixture.componentInstance.open()).toBe(false);
    expect(spy).not.toHaveBeenCalled();
  });

  it('Đồng ý: phát confirmed một lần rồi đóng', async () => {
    const spy = vi.fn();
    fixture.componentInstance.confirmed.subscribe(spy);
    buttons().find((b) => b.textContent?.includes('Đồng ý'))!.click();
    await fixture.whenStable();
    expect(spy).toHaveBeenCalledTimes(1);
    expect(q('[role=dialog]')).toBeNull();
  });

  it('Escape: đóng', async () => {
    document.dispatchEvent(new KeyboardEvent('keydown', { key: 'Escape' }));
    await fixture.whenStable();
    expect(fixture.componentInstance.open()).toBe(false);
  });
});
