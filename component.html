Component: từ SFC sang class + template

Cấu trúc một component standalone, selector, imports, template và style, so với file .vue. Cây component và cách chia nhỏ.

Học xong bài này bạn sẽ:
  • Viết component standalone đầy đủ
  • Hiểu imports của component thay cho đăng ký component trong Vue
  • Chia giao diện thành cây component hợp lý

#Giải phẫu một component

src/app/features/class-card/class-card.ts
import { Component, input } from '@angular/core';
import { DecimalPipe } from '@angular/common';
import { Badge } from '../../shared/badge/badge';

@Component({
  selector: 'app-class-card',                // 1. tên thẻ dùng trong template khác
  imports: [Badge, DecimalPipe],             // 2. component / directive / pipe mà template này dùng
  templateUrl: './class-card.html',          // 3. template (hoặc template: `...`)
  styleUrl: './class-card.css',              // 4. style riêng (hoặc styles: `...`)
  host: { class: 'card', '[class.full]': 'isFull()' }, // 5. thuộc tính trên chính thẻ <app-class-card>
})
export class ClassCard {                     // 6. class: dữ liệu và hành vi
  name = input.required<string>();
  students = input(0);
  capacity = input(40);

  protected isFull() {
    return this.students() >= this.capacity();
  }
}
class-card.html
<h3>{{ name() }}</h3>
<p>{{ students() }} / {{ capacity() }} học sinh</p>
@if (isFull()) {
  <app-badge tone="red">Đã đủ sĩ số</app-badge>
}
nơi dùng
<app-class-card name="Lớp 5A" [students]="30" [capacity]="30" />
<app-class-card name="Lớp 5B" [students]="12" />

#Selector và thẻ host

Khi Angular render <app-class-card>, thẻ đó thật sự xuất hiện trong DOM, bao quanh nội dung template. Vue thì không: component Vue thay thế bằng phần tử gốc của template.

DOM thật sau khi render
<app-class-card class="card full">       <!-- thẻ host -->
  <h3>Lớp 5A</h3>
  <p>30 / 30 học sinh</p>
  <app-badge tone="red">...</app-badge>
</app-class-card>

Thẻ host mặc định là display: inline (vì trình duyệt coi thẻ lạ là inline). Khi đặt component vào flex / grid hoặc cho nó width, nhớ thêm vào style của component: :host { display: block; }. Đây là lỗi bố cục số một của người mới.

Quy ước selector:

  • Có tiền tố của dự án (mặc định app-, có thể đổi trong angular.json) để không trùng thẻ HTML hay thư viện khác.
  • Viết kebab-case: app-class-card.
  • Selector còn có thể là thuộc tính [appTooltip] hay class, nhưng đó là cho directive (bài 8).

#imports: component phải tự khai báo những gì nó dùng

Đây là điểm khác lớn nhất với Vue <script setup>. Template Angular chỉ hiểu những component, directive, pipe có trong imports của chính component đó.

Cơ chế này giống đăng ký component cục bộ của Vue Options API (components: { Badge }), không phải đăng ký toàn cục app.component(). Angular không có đăng ký toàn cục: mọi phụ thuộc phải ghi rõ, nhờ vậy builder biết chính xác component nào cần đóng gói, và lazy loading tách bundle rất chuẩn.

Inline (template: `...`)File riêng (templateUrl)
giống SFC: nhìn một file là đủfile .html riêng, editor hỗ trợ HTML tốt hơn

Hai cách giống nhau hoàn toàn về hiệu năng. Angular Language Service hỗ trợ cả template inline (gợi ý, báo lỗi trong chuỗi template).

#Chia nhỏ thành cây component

Một trang danh sách lớp chia thành các component như sau:

  • Component "thông minh" (container, smart): biết lấy dữ liệu ở đâu (inject service), xử lý sự kiện, điều hướng. Thường là component của một trang.
  • Component "trình bày" (presentational, dumb): chỉ nhận input, phát output, không inject service dữ liệu. Dễ dùng lại và dễ test.

Đây đúng là cách bạn tổ chức Vue tốt: trang gọi composable / store, component con chỉ nhận props và emit. Angular không bắt buộc, nhưng hầu hết dự án lớn theo cách này.

#Component cũ với NgModule

Trong dự án viết trước Angular 15, component được khai báo trong NgModule thay vì tự imports:

classes.module.ts (kiểu cũ)
@NgModule({
  declarations: [ClassListComponent, ClassCardComponent], // component "thuộc" module này
  imports: [CommonModule, SharedModule, ClassesRoutingModule],
  exports: [ClassCardComponent],
})
export class ClassesModule {}

@Component({
  selector: 'app-class-card',
  templateUrl: './class-card.component.html',
  standalone: false,            // từ v19 standalone là mặc định, component cũ phải ghi rõ false
})
export class ClassCardComponent {}

Component standalone và component trong NgModule dùng chung được: module import component standalone, component standalone import module. Lệnh ng g @angular/core:standalone giúp chuyển dần dự án cũ sang standalone.

Câu hỏi nhanh. Component dùng <app-badge> trong template nhưng chỉ có dòng import TypeScript. Kết quả?

Template chỉ biết những gì nằm trong imports của @Component. Import TypeScript thôi là chưa đủ.

Câu hỏi nhanh. Component nằm trong một hàng flex nhưng width: 300px không có tác dụng. Nguyên nhân hay gặp nhất?

Thẻ tự đặt tên như app-class-card là phần tử inline với trình duyệt.

#Bài tập

Component StudentRow và danh sách

Viết component StudentRow hiển thị tên học sinh, số bài đã nộp trên tổng số bài, và tô đỏ nếu nộp dưới một nửa. Viết StudentList dùng StudentRow cho 3 học sinh cố định.

Gợi ý từng bước

  1. StudentRow: 3 input bắt buộc name, done, total.
  2. Dùng computed để tính low = done / total < 0.5.
  3. Tô đỏ bằng host binding: host: { '[class.low]': 'low()' } và style :host(.low) { color: #dc2626; }.
  4. StudentList import StudentRow, dùng @for qua một mảng (bài 5 sẽ nói kỹ, ở đây chỉ cần @for (s of students; track s.id) { ... }).
Xem lời giải
student-row.ts
import { Component, computed, input } from '@angular/core';

@Component({
  selector: 'app-student-row',
  template: `
    <span class="name">{{ name() }}</span>
    <span>{{ done() }} / {{ total() }} bài</span>
  `,
  styles: `
    :host { display: flex; justify-content: space-between; padding: 8px 12px; border-bottom: 1px solid #e2e8f0; }
    :host(.low) { color: #dc2626; font-weight: 600; }
  `,
  host: { '[class.low]': 'low()' },
})
export class StudentRow {
  name = input.required<string>();
  done = input.required<number>();
  total = input.required<number>();
  protected low = computed(() => this.total() > 0 && this.done() / this.total() < 0.5);
}
student-list.ts
import { Component } from '@angular/core';
import { StudentRow } from './student-row';

@Component({
  selector: 'app-student-list',
  imports: [StudentRow],
  template: `
    @for (s of students; track s.id) {
      <app-student-row [name]="s.name" [done]="s.done" [total]="10" />
    }
  `,
})
export class StudentList {
  protected students = [
    { id: 1, name: 'Nguyễn An', done: 9 },
    { id: 2, name: 'Trần Bình', done: 3 },
    { id: 3, name: 'Lê Chi', done: 6 },
  ];
}

Giải thích: host gắn class low lên chính thẻ <app-student-row>, và :host(.low) chọn thẻ host khi có class đó. :host { display: flex } khiến thẻ host trở thành hàng flex, nên không cần thêm thẻ div bọc ngoài. Kiểm tra total() > 0 để tránh chia cho 0.
