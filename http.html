Gọi API: HttpClient, interceptor, resource

provideHttpClient, gọi GET / POST có kiểu, interceptor dạng hàm (token, lỗi, loading), xử lý lỗi, httpResource và resource cho dữ liệu dạng signal.

Học xong bài này bạn sẽ:
  • Gọi API có kiểu và xử lý lỗi
  • Viết interceptor gắn token và bắt lỗi chung
  • Dùng httpResource để tải dữ liệu theo signal
