Dependency injection và service

Service, inject(), providedIn root, provider ở component / route, injection token, useFactory / useValue / useClass. So với provide / inject và composable của Vue.

Học xong bài này bạn sẽ:
  • Tách logic ra service và inject vào component
  • Hiểu cây injector và phạm vi của service
  • Dùng InjectionToken cho cấu hình

#Vấn đề DI giải quyết

Ở Vue, khi nhiều component cần cùng một logic (gọi API lớp học, giữ người dùng đăng nhập), bạn viết composable useClasses() hoặc store Pinia, rồi import thẳng vào component. Angular giải bằng service và dependency injection (DI): component không tự tạo hay import trực tiếp đối tượng nó cần, mà "xin" Angular đưa cho.

features/classes/class-api.ts
import { Injectable, inject } from '@angular/core';
import { HttpClient } from '@angular/common/http';

@Injectable({ providedIn: 'root' })   // một bản duy nhất cho cả ứng dụng, tạo khi lần đầu cần
export class ClassApi {
  private http = inject(HttpClient);   // service cũng inject service khác

  list() {
    return this.http.get<Classroom[]>('/api/classes');
  }
}
features/classes/class-list-page.ts
export class ClassListPage {
  private api = inject(ClassApi);      // xin Angular đưa bản ClassApi
  classes = toSignal(this.api.list(), { initialValue: [] });
}

So với Vue: providedIn: 'root' giống một store Pinia (singleton toàn ứng dụng). inject() giống cả useStore() lẫn inject() của Vue. Khác biệt lớn: Angular có cây injector, nên bạn có thể cho một nhánh component dùng một bản service riêng, hoặc thay hẳn cài đặt (khi test, khi chạy SSR) mà không sửa component.

#inject(): chỉ gọi được ở đâu

inject() chỉ chạy trong injection context:

  • khởi tạo thuộc tính của class (private api = inject(ClassApi)),
  • constructor của component, directive, pipe, service,
  • hàm factory của provider, guard / resolver / interceptor dạng hàm,
  • trong runInInjectionContext(injector, () => ...).
TypeScriptSai / nguy hiểm
save() {
  const api = inject(ClassApi);   // ✘ NG0203: inject() must be called from an injection context
}

Cách cũ (vẫn hợp lệ) là inject qua tham số constructor: constructor(private api: ClassApi) {}. Cách mới gọn hơn, chạy tốt với kế thừa và hàm.

#Service giữ state: thay cho Pinia

core/auth.ts
@Injectable({ providedIn: 'root' })
export class Auth {
  private http = inject(HttpClient);
  private readonly _user = signal<User | null>(null);

  readonly user = this._user.asReadonly();            // bên ngoài chỉ đọc
  readonly isLoggedIn = computed(() => this._user() !== null);
  readonly isTeacher = computed(() => this._user()?.role === 'teacher');

  async login(email: string, password: string) {
    const u = await firstValueFrom(this.http.post<User>('/api/login', { email, password }));
    this._user.set(u);
  }

  logout() {
    this._user.set(null);
  }
}
dùng ở bất kỳ component nào
export class Header {
  protected auth = inject(Auth);
}
Template
@if (auth.user(); as u) {
  <span>{{ u.name }}</span> <button (click)="auth.logout()">Đăng xuất</button>
} @else {
  <a routerLink="/dang-nhap">Đăng nhập</a>
}

Mẫu "signal private + asReadonly public + method thay đổi" giữ cho chỉ service mới sửa được state, giống state / getters / actions của Pinia. Bài 15 đi sâu hơn.

Đây chính là provide() trong component cha và inject() trong con của Vue, nhưng tự động hơn: bạn đăng ký class, Angular tự tạo instance, tự inject cả phụ thuộc của nó.

#Hàm inject kiểu composable

Vì inject() là hàm, bạn viết được "composable" của Angular: hàm tiện ích gọi inject bên trong, dùng trong khởi tạo thuộc tính.

shared/use-route-id.ts
export function injectRouteNumber(name: string) {
  const route = inject(ActivatedRoute);
  return toSignal(route.paramMap.pipe(map((p) => Number(p.get(name)))), { initialValue: NaN });
}

// trong component
classId = injectRouteNumber('id');

Quy ước đặt tên: hàm phải gọi trong injection context thường bắt đầu bằng inject (injectRouteNumber) để người đọc biết không được gọi trong method thường.

Câu hỏi nhanh. Muốn mỗi lần mở trang chấm bài có một bản GradingSession mới, dùng chung cho các component con của trang. Khai báo thế nào?

Provider ở component tạo một bản cho mỗi instance và chia sẻ cho cây con. new thì mỗi con một bản riêng, không dùng chung được.

Câu hỏi nhanh. Gọi inject(Auth) trong method onClick(). Kết quả?

#Bài tập

Service thông báo (toast) dùng toàn ứng dụng

Viết service Toast có success(msg), error(msg), tự ẩn sau 3 giây, tối đa 3 thông báo cùng lúc. Viết component ToastHost đặt một lần trong App để hiển thị. Gọi thử từ một component khác.

Gợi ý từng bước

  1. Service: items = signal<readonly ToastItem[]>([]), mỗi item có id, kind, text.
  2. show() thêm item (cắt còn 3 cái mới nhất bằng slice(-3)), đặt setTimeout 3 giây để xoá theo id.
  3. ToastHost inject Toast và lặp @for qua toast.items().
  4. Component khác chỉ cần inject(Toast).success('Đã lưu').
Xem lời giải
core/toast.ts
import { Injectable, signal } from '@angular/core';

export interface ToastItem { id: number; kind: 'success' | 'error'; text: string }

@Injectable({ providedIn: 'root' })
export class Toast {
  private seq = 0;
  private readonly _items = signal<readonly ToastItem[]>([]);
  readonly items = this._items.asReadonly();

  success(text: string) { this.show('success', text); }
  error(text: string) { this.show('error', text); }

  dismiss(id: number) {
    this._items.update((list) => list.filter((t) => t.id !== id));
  }

  private show(kind: ToastItem['kind'], text: string) {
    const id = ++this.seq;
    this._items.update((list) => [...list, { id, kind, text }].slice(-3));
    setTimeout(() => this.dismiss(id), 3000);
  }
}
core/toast-host.ts
@Component({
  selector: 'app-toast-host',
  template: `
    <div class="stack" aria-live="polite">
      @for (t of toast.items(); track t.id) {
        <div class="toast" [class.error]="t.kind === 'error'" (click)="toast.dismiss(t.id)">{{ t.text }}</div>
      }
    </div>
  `,
  styles: `
    .stack { position: fixed; right: 16px; bottom: 16px; display: grid; gap: 8px; z-index: 50; }
    .toast { background: #166534; color: #fff; padding: 10px 14px; border-radius: 10px; cursor: pointer; }
    .error { background: #b91c1c; }
  `,
})
export class ToastHost {
  protected toast = inject(Toast);
}
dùng thử ở component bất kỳ
export class SaveButton {
  private toast = inject(Toast);
  save() {
    this.toast.success('Đã lưu điểm cho 12 em');
  }
}

Giải thích: Toast là singleton nên mọi component gọi vào cùng một danh sách, ToastHost đặt một lần ở gốc là đủ. aria-live="polite" giúp trình đọc màn hình đọc thông báo mới. Mảng được tạo mới mỗi lần (spread, filter, slice) để signal báo cập nhật. Bản thật nên cho thông báo lỗi ở lâu hơn và có nút đóng rõ ràng.
