Hiệu năng

Lazy loading, @defer, track, NgOptimizedImage, virtual scroll, đo bằng Angular DevTools và Lighthouse, bundle budget và phân tích bundle.

Học xong bài này bạn sẽ:
  • Giảm kích thước bundle ban đầu
  • Tìm và sửa chỗ render chậm
  • Đặt budget để không phình bundle

#Giảm bundle ban đầu

  1. Lazy load mọi route bằng loadComponent / loadChildren (bài 11).
  2. @defer cho phần nặng ít khi cần ngay: biểu đồ, trình soạn thảo, bản đồ, phần cuối trang (bài 5).
  3. Import động cho thư viện chỉ dùng khi người dùng bấm:
    TypeScript
    async exportExcel() {
  const XLSX = await import('xlsx');                 // chỉ tải khi bấm nút
  const ws = XLSX.utils.json_to_sheet(this.rows());
  ...
}
  4. Chọn thư viện nhẹ: date-fns thay moment, import từng icon thay vì cả bộ, kiểm tra kích thước trên bundlephobia trước khi cài.

#Ảnh: NgOptimizedImage

TypeScript
import { NgOptimizedImage } from '@angular/common';

@Component({
  imports: [NgOptimizedImage],
  template: `
    <img ngSrc="/brand/hero.webp" width="1200" height="630" priority alt="Sổ bài tập" />   <!-- ảnh LCP -->
    <img ngSrc="/avatars/{{ id() }}.webp" width="48" height="48" alt="" />                <!-- tự lazy -->
  `,
})

ngSrc bắt buộc có width / height (tránh nhảy bố cục), tự thêm loading="lazy", priority thêm fetchpriority="high" và cảnh báo nếu ảnh LCP bị lazy. Có loader cho CDN ảnh (Cloudinary, imgix, Cloudflare) để tự sinh srcset.

#Danh sách dài

  • Luôn track theo id: tránh tạo lại DOM.
  • Phân trang ở server thay vì tải 5.000 dòng.
  • Virtual scroll khi buộc phải hiện nhiều dòng: chỉ render các dòng đang nằm trong khung nhìn.
TypeScript
import { ScrollingModule } from '@angular/cdk/scrolling';

@Component({
  imports: [ScrollingModule],
  template: `
    <cdk-virtual-scroll-viewport itemSize="48" class="list">
      <div *cdkVirtualFor="let s of students(); trackBy: byId" class="row">{{ s.name }}</div>
    </cdk-virtual-scroll-viewport>
  `,
  styles: `.list { height: 480px; } .row { height: 48px; }`,
})

#Bài tập

Giảm thời gian tải trang chấm bài

Trang chấm bài hiện có trong bundle chính: thư viện xem ảnh có zoom (120 KB), thư viện vẽ biểu đồ điểm (180 KB) hiển thị ở cuối trang, và thư viện xuất PDF (250 KB) dùng khi bấm "In bảng điểm". Trang đang được import thẳng trong app.routes.ts. Hãy sắp xếp lại để main.js nhỏ nhất, và đặt budget.

Gợi ý từng bước

  1. Route: đổi component: GradingPage thành loadComponent.
  2. Xem ảnh: cần ngay khi mở bài nộp, nhưng chỉ khi người dùng bấm vào ảnh mới cần zoom → @defer (on interaction).
  3. Biểu đồ cuối trang → @defer (on viewport) có placeholder đúng kích thước.
  4. PDF → await import() trong hàm in.
  5. Budget initial 400kB / 500kB.
Xem lời giải

{ path: 'lop/:classId/cham-bai', loadComponent: () => import('./grading/grading-page').then((m) => m.GradingPage) },

}
