# Angular cho dân Vue

Lộ trình học Angular hiện đại (standalone, signals, control flow mới, zoneless) dành cho lập trình viên đã quen Vue: 25 bài, đối chiếu từng khái niệm với Vue, sơ đồ, code chạy được, khung minh hoạ kết quả, câu hỏi nhanh và bài tập có lời giải.

Xem trang: mở `index.html` (GitHub Pages phục vụ thẳng từ gốc repo).

Sửa nội dung trong `src/lessons/*.html`, `src/pages/*.html`, rồi dựng lại:

```bash
node build.mjs
```
