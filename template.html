Cú pháp template: binding và event

Interpolation, property binding, attribute / class / style binding, event binding, two-way binding, template reference, @let. Đối chiếu với v-bind, v-on, v-model.

Học xong bài này bạn sẽ:
  • Dùng đúng 4 kiểu binding
  • Phân biệt property và attribute binding
  • Dịch được mọi cú pháp template Vue sang Angular

#Bốn kiểu binding

Toàn bộ cú pháp template Angular xoay quanh 4 dấu ngoặc. Nhớ được bảng này là đọc được 90% template:

Cú phápHướngVí dụVue
{{ biểu thức }}class → giao diện (chữ){{ name() }}{{ name }}
[thuộc tính]="biểu thức"class → giao diện (thuộc tính)[disabled]="saving()":disabled="saving"
(sự kiện)="câu lệnh"giao diện → class(click)="save()"@click="save"
[(giá trị)]="signal"hai chiều[(value)]="query"v-model="query"

Mẹo nhớ: ngoặc vuông [ ] như hộp chứa giá trị đưa vào, ngoặc tròn ( ) như tai nghe lắng nghe sự kiện. [( )] người ta gọi vui là "banana in a box" (quả chuối trong hộp).

#Interpolation

Template
<h2>{{ classroom().name }}</h2>
<p>Sĩ số: {{ students().length }} / {{ capacity }}</p>
<p>Điểm trung bình: {{ average() | number: '1.1-1' }}</p>
<p>{{ isFull() ? 'Đã đủ' : 'Còn chỗ' }}</p>
<p>{{ teacher()?.name ?? 'Chưa phân công' }}</p>

Biểu thức trong template Angular là một tập con của JavaScript: có ?., ??, toán tử ba ngôi, gọi hàm, template literal (từ v19.2: {{ `Lớp ${name()}` }}). Không có: gán (=), new, ++, toán tử bit, truy cập biến toàn cục như window hay Math (muốn dùng thì gán vào thuộc tính của class).

Giữ biểu thức trong template đơn giản và rẻ. Gọi một method tính toán nặng như {{ tinhXepHang() }} sẽ bị chạy lại mỗi lần Angular kiểm tra giao diện. Đặt nó vào computed(): chỉ tính lại khi phụ thuộc đổi (giống computed của Vue so với method).

#Property binding

Template
<img [src]="avatarUrl()" [alt]="name()" />
<button [disabled]="saving() || !valid()">Lưu</button>
<input [value]="query()" />
<app-class-card [name]="c.name" [students]="c.count" />
<a [href]="docUrl">Hướng dẫn</a>

Không có ngoặc vuông thì giá trị là chuỗi tĩnh:

Template
<app-class-card name="Lớp 5A" />          <!-- input name nhận chuỗi 'Lớp 5A' -->
<app-class-card [name]="'Lớp 5A'" />      <!-- giống hệt, dài hơn -->
<app-class-card [students]="30" />        <!-- số 30 -->
<app-class-card students="30" />          <!-- chuỗi '30': lỗi kiểu nếu input là number -->

Property hay attribute?

Ngoặc vuông gán vào property của DOM, không phải attribute HTML. Hầu hết trùng tên nên bạn không để ý, nhưng một số attribute không có property tương ứng (aria-*, colspan trên một số phần tử, data-*, thuộc tính SVG). Khi đó dùng attr.:

Template
<button [attr.aria-label]="'Xoá ' + name()" [attr.aria-expanded]="open()">✕</button>
<td [attr.colspan]="span()">...</td>
<div [attr.data-id]="id()">...</div>
<!-- Từ v20, aria-* gán được trực tiếp: [aria-label]="..." -->

Giá trị null hoặc undefined trong [attr.x] sẽ xoá attribute, đúng điều bạn muốn với aria-* tuỳ chọn.

Class và style

Template
<!-- một class bật / tắt -->
<li [class.done]="a.status === 'graded'">...</li>

<!-- nhiều class: chuỗi, mảng hoặc object (giống :class của Vue) -->
<div [class]="'card ' + tone()"></div>
<div [class]="['card', tone()]"></div>
<div [class]="{ card: true, active: selected(), danger: late() }"></div>

<!-- style -->
<div [style.width.px]="width()"></div>
<div [style.background-color]="color()"></div>
<div [style]="{ 'grid-template-columns': cols(), opacity: dim() ? 0.5 : 1 }"></div>

Giống :class và :style của Vue, kể cả cách gộp với class="..." tĩnh. Cú pháp [style.width.px] (thêm đơn vị vào tên) là riêng của Angular và rất tiện. [ngClass], [ngStyle] là cách cũ, không cần dùng nữa.

#Event binding

protected onSearch(e: Event) {
  const text = (e.target as HTMLInputElement).value;
  this.query.set(text.trim());
}

#Two-way binding

Với component con có model() (bài 7) hoặc với signal, cú pháp [( )] làm cả hai chiều:

TypeScript
@Component({
  selector: 'app-search',
  imports: [FormsModule],
  template: `
    <input [(ngModel)]="query" placeholder="Tìm học sinh" />
    <app-toggle [(checked)]="onlyLate" /> Chỉ học sinh nộp muộn
    <p>Đang tìm: "{{ query() }}", chỉ nộp muộn: {{ onlyLate() }}</p>
  `,
})
export class Search {
  query = signal('');
  onlyLate = signal(false);
}

Đang tìm: "Lan", chỉ nộp muộn: true

[(ngModel)]="query" là cách nhanh nhất để có "v-model" cho ô nhập: cần import FormsModule, và truyền signal (không gọi query()). Với form thật nhiều trường, dùng reactive forms (bài 12).

[(ngModel)]="query()" (có ngoặc gọi hàm) là sai: bạn đang truyền giá trị, Angular không ghi ngược lại được. Two-way binding với signal: truyền chính signal, [(ngModel)]="query".

#Template reference variable

#ten đặt tên cho một phần tử hay component để dùng ở chỗ khác trong cùng template, không cần viết code trong class:

Template
<input #box placeholder="Tên lớp" />
<button (click)="add(box.value); box.value = ''; box.focus()">Thêm</button>

<app-date-picker #picker />
<button (click)="picker.open()">Chọn ngày</button>

Giống ref="box" của Vue, nhưng dùng được thẳng trong template mà không cần khai báo const box = ref() trong script. Muốn truy cập từ class thì dùng viewChild('box') (bài 7).

#Bài tập

Thẻ bài tập có trạng thái và nút hành động

Viết component hiển thị một bài tập: tiêu đề, hạn nộp, nhãn trạng thái có màu (nháp xám, đã giao xanh, quá hạn đỏ), nút "Giao bài" chỉ bật khi đang là nháp, và ô ghi chú nhập trực tiếp (hiển thị số ký tự đã gõ / 200).

Gợi ý từng bước

  1. State: status = signal<'draft' | 'published'>('draft'), due = signal('2026-11-10'), note = signal('').
  2. Quá hạn: late = computed(() => this.status() === 'published' && this.due() < hôm nay) (so sánh chuỗi YYYY-MM-DD được).
  3. Nhãn: [class]="{ tag: true, gray: ..., green: ..., red: late() }".
  4. Nút: [disabled]="status() !== 'draft'", (click)="status.set('published')".
  5. Ghi chú: [value]="note()" và (input) cập nhật signal, maxlength="200".
Xem lời giải
assignment-card.ts
import { Component, computed, signal } from '@angular/core';

const today = () => new Date().toISOString().slice(0, 10);

@Component({
  selector: 'app-assignment-card',
  template: `
    <h3>Bài 3: Phân số</h3>
    <p>Hạn nộp: {{ due() }}</p>
    <span [class]="{ tag: true, gray: status() === 'draft', green: status() === 'published' && !late(), red: late() }">
      {{ late() ? 'Quá hạn' : status() === 'draft' ? 'Nháp' : 'Đã giao' }}
    </span>
    <button [disabled]="status() !== 'draft'" (click)="status.set('published')">Giao bài</button>

    <label for="note">Ghi chú</label>
    <textarea id="note" maxlength="200" [value]="note()" (input)="onNote($event)"></textarea>
    <small>{{ note().length }}/200</small>
  `,
  styles: `
    :host { display: block; border: 1px solid #e2e8f0; border-radius: 12px; padding: 14px; }
    .tag { padding: 2px 10px; border-radius: 99px; font-size: 13px; margin-right: 8px; }
    .gray { background: #f1f5f9; } .green { background: #dcfce7; color: #166534; } .red { background: #fee2e2; color: #b91c1c; }
    textarea { display: block; width: 100%; margin-top: 6px; }
  `,
})
export class AssignmentCard {
  protected status = signal<'draft' | 'published'>('draft');
  protected due = signal('2026-11-10');
  protected note = signal('');
  protected late = computed(() => this.status() === 'published' && this.due() < today());

  protected onNote(e: Event) {
    this.note.set((e.target as HTMLTextAreaElement).value);
  }
}
